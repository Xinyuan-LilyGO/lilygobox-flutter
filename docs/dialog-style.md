# 标准提示框与操作按钮

新增添加、编辑、确认类窗口以“编辑服务”提示框为视觉基准，优先组合公共模板，不在功能页面单独定义字体、灰色按钮或平行弹窗样式。

## 公共模板

- 标准模态提示框使用 `lib/core/widgets/confirmation_dialog.dart` 的 `AppDialog`；简单二次确认优先调用 `showAppConfirmation`。不要直接新建一套 `AlertDialog`、`Dialog` 外观。
- 统一视觉规格由 `lib/core/widgets/dialog_style.dart` 的 `AppDialogStyle` 提供，操作按钮使用 `AppActionButton.dialog`。已有普通 `AppActionButton` 在对话框内也自动使用公共灰色底色和默认 12px 操作文字；显式字号覆盖只用于确有特殊需求的场景。
- 嵌入式批准面板只复用公共操作按钮，通过 `AppDialogScope` 声明按钮所在的实际背景。保留面板已有的双层背景、圆角、字号和留白，不套用模态提示框的容器或文字规格，也不新增遮罩。

## 外观与文字

- 承载背景统一为 `AppDialogStyle.backgroundColor(theme)`，即编辑服务使用的 `theme.materialColors.surfaceContainerHigh`；圆角 12px。此容器规则仅适用于标准模态提示框。提示背景和表单输入控件分别使用各自的背景层级。
- 窗口标题使用 18px、常规字重及 `theme.textColorPrimary`。嵌入式批准面板沿用既有 15px 加粗标题与实心盾牌，不受此标题规格影响。
- 正文中的字段主标题、用途说明遵循[主标题与次标题文字规范](text-input-style.md#主标题与次标题文字规范)：12px 次级文字、11px 三级文字与 1.4 行高。说明紧跟所属标题，两者之间不插入控件。
- 内容通常采用 24px 水平留白；字段间距 16px，标题到说明 4px，说明到控件 8px。弹窗标题、内容、操作区沿用 `AppDialog` 的布局；嵌入式批准面板保留自身留白，内容较长时内部滚动，操作按钮始终可见。
- 继承应用字体与系统文字缩放；窄窗口下允许说明换行、按钮换行，不压缩字号或截断关键信息。

## 按钮规格与配色

- 取消、拒绝、读取模型列表等普通按钮统一使用 12px、常规字重、左右 14px / 上下 8px 内边距、8px 圆角。
- 保存、添加、允许一次等主要按钮统一使用 12px、w600、左右 16px / 上下 8px 内边距、10px 圆角。主要操作使用主题紫色与白色文字。
- 操作按钮靠右排列，水平间距 8px，空间不足时换行并保留间距。
- **浅色提示框及纯白表面上的灰色按钮，统一参考“添加文件夹”：实际承载背景向主题主文字色混合 6%。** 不从其他页面搬用较深的灰色，也不对浅色主题进行额外透明叠加。深色主题保留原有普通按钮层级；主要紫色按钮不套用此灰色规则。
- 灰色、紫色按钮的悬停渐变、按下反馈、波纹与禁用状态继续由公共 `AppActionButton` 和 `MenuItemSurface` 管理，不在调用页重写。

新增同类窗口时先选用上述模板，特殊尺寸仅在内容需要时调整；不要因所在功能不同而重复创建按钮配色和文字样式。

当需求只涉及按钮时，修改范围仅限按钮及其公共配色、字号和交互；不得连带调整所属面板的背景、文字层级、圆角或布局。
