# 全局数值滑条样式

应用内数值调节滑条统一使用 `lib/core/widgets/app_capsule_slider.dart` 的 `AppCapsuleSlider`，目前覆盖设备亮度、音量、振动及 AI 思考强度。新增数值滑条继续复用此组件，避免页面单独绘制轨道。

未填充区域使用居中的 4px 圆角细轨道，起止位置分别对齐最小值和最大值的滑块中心；不要延伸至控件外沿，避免最后一个等级节点右侧出现多余尾段。每端缩进为胶囊高度的一半，标准高度 36px 时为 18px。固定等级点使用同一组中心位置，未填充区域的等级点使用主题主文字色，与中性灰轨道保持清晰区分，末端圆点与细轨道圆角相接，不再向外拖出一截线。

已填充区域仍为完整高度的圆角胶囊，最大值时可以覆盖控件全宽。暗色主题的未填充轨道使用主题主文字色以 45% 不透明度叠加到 secondary 背景，形成清晰的浅灰色细轴；亮色主题同样使用中性灰色：主题主文字色以 6% 不透明度叠加到更浅的 primary 背景（不再以 secondary 灰色为底），未填充细轨道不混入主题紫色。此规则不改变控件宽度、点击范围、数值映射、图标或禁用状态。连续滑条保持连续调节；等级滑条保留拖动跟随、松手吸附、按压动画及键盘操作。等级交互详见 [AI 思考强度](ai-reasoning-effort.md)。

此处的滑条指亮度、音量等数值调节控件，不包括页面滚动条 `Scrollbar`、加载进度条或窗口分隔拖动条。

思考强度等启用 `snapToDivisions` 的等级滑条，点击轨道节点时，滑块从当前位置以 150 ms 平滑移动到目标节点，不能先跳到点击位置再执行吸附。实际拖动时连续跟随鼠标，松手后吸附最近节点；键盘调节保留相同移动动画。系统减少动画时立即定位。
