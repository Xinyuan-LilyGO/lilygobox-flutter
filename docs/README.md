- [全局数值滑条样式](slider-style.md)：共享胶囊滑条、细轨道端点与等级节点对齐规则。
- [AI 回复耗时与详情](assistant-response-details.md)：回复状态与用时、请求重试、错误记录、设置操作详情、Markdown 渲染、复制与消息时间。
