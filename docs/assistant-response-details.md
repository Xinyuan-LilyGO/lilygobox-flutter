# AI 回复耗时与详情

模型选择菜单的滚动条沿用全局自动显隐行为，不强制常显。列表右侧在滚动视口外预留 20 px，滚动条容器距菜单右沿 4 px，模型项背景、文字和勾选图标不会被滚动条遮挡；局部使用 `AppScrollBehavior(scrollbars: false)` 保留平滑滚轮动画，并避免重复滚动条。

每轮回复在正文顶部显示当前状态、计时和分隔线。首次请求尚未收到响应头时显示“正在连接”，收到成功响应、等待正文时显示“正在思考”，正文增量到达后显示“正在输出”。设置工具执行结束后再次请求模型时，显示“设置操作已结束，正在等待模型回复”，避免误认为尚未连接就执行了设置。准备设置操作、实际执行、暂停、重试、失败和停止分别显示对应状态；完成后显示最终用时。状态来自真实请求和工具事件，不根据等待时长猜测，也不在正文底部追加思考状态。

## 默认折叠的过程记录

“正在思考”阶段收到思考正文后，将该状态行直接合并为思考内容项，沿用阶段开始时间，不再并列显示两条。思考进行时标题为“正在思考”，转入其他阶段后改为“模型思考”；未返回思考正文时保留原状态行。

点击“用时／当前状态”行展开本轮过程，默认收起，不随请求阶段自动展开。展开后按事件实际发生顺序显示相对于本轮开始的时间、请求阶段、模型返回的思考内容、中途说明、设置操作的具体目标及成功／失败结果、后续请求和重试原因。顶部总用时和各过程项时间统一显示毫秒：小时未满时使用 `MM:SS:mmm`，达到一小时后使用 `HH:MM:SS:mmm`。模型思考内容使用与设备卡片相同的点阵图标；工具调用成功使用扳手图标，失败使用错误图标；普通进行中状态使用实心圆点，整轮完成使用勾。回合结束后不显示没有思考正文的“正在思考”状态项，实际收到的思考内容仍保留。过程较长时在最高 300 px 的详情视口内滚动，右侧留出滚动条空间；最终答复显示在过程区域之外。思考增量合并为连续段落，最多每 16 ms 通知一次界面更新。

Chat Completions 读取接口主动返回的 `reasoning_content`（或字符串形式的 `reasoning`）；Responses 读取推理摘要的流式事件和完成响应中的公开摘要。完成事件与增量重复的摘要不会追加两次。`encrypted_content` 不作为可读文本展示。模型或供应商未返回可展示的思考内容时，仅记录实际请求和操作事件，不生成、猜测或补写思考文本。

同一轮中的多次模型请求共享一份过程记录；工具调用前的助手说明归入过程，后续答复不会将它覆盖丢失。设置结果明确显示成功或失败；没有执行操作时不额外显示提示。Chat Completions 的模型原始思考字段随对应助手消息回放，兼容需要工具上下文的推理模型；本地状态、耗时和过程记录本身不会发送给模型。

标准 SSE 响应按服务端增量立即显示，不再额外拆字或延迟播放；若兼容服务忽略流式请求并返回完整 JSON，正文一次显示。暂停会暂停网络接收和待显示文本，继续后立即显示已缓存内容。停止后保留已显示的部分文本及已记录的思考、操作和重试过程。

客户端只合并同一轮队列中已经收到的文本，不设置人为输出间隔。收到结束信号且缓存处理完毕后立即进入完成状态，不等待打字动画；实际响应速度仍由模型服务和网络决定。

输出队列必须先登记异步任务，再开始消费增量。单字或分散到达的 SSE 增量可能立即排空，不能将已结束的任务重新登记为运行中，否则回复结束时会形成微任务循环并阻塞界面。回归测试须覆盖单字 JSON、间隔到达的单字 SSE，以及单字输出后的流中断。

计时在暂停时冻结、继续后累计。耗时覆盖用户发送到最终回复完成的全过程，包括助手发起的设置操作和后续模型请求。模型服务配置不会显示 API 密钥。

## 请求失败与重试

请求错误保存在对应轮次的消息中，显示“处理失败”和可复制的错误详情。即使没有收到正文也保留失败轮次；后续发送消息或修改模型服务不会清除之前的错误。错误和重试记录仅供界面展示，不作为助手回复发送给模型。会话仍按现有规则仅保存在内存中，清空会话或退出应用后不保留。

仅对未输出正文或工具调用的临时故障自动重试：网络请求异常、超时、HTTP 408、429 和 5xx。最多重试 2 次，默认分别等待 1 秒和 2 秒；服务端提供数字形式的 `Retry-After` 时使用该秒数，最长等待 30 秒。无效密钥、权限或参数错误不自动重试。显示“正在重试模型请求（当前次数/2）”，每次重试原因保留在本轮详情中。

收到正文或工具调用后发生的流中断直接结束为失败，保留已显示的正文，不自动重发，避免重复内容或重复执行设置。停止或销毁会话会取消等待中的重试，不作为请求失败展示。

## Markdown 与消息操作

助手正文使用 `flutter_markdown_plus` 渲染常用 Markdown：标题、加粗、斜体、有序／无序列表、引用、行内代码、代码块、链接和表格。样式复用当前主题字段，表格按消息可用宽度分配列宽并换行。用户发送的正文保留原样，不将用户输入的 Markdown 符号转换为富文本。流式增量立即刷新正文，不添加打字播放。

每条用户消息和助手回复在正文下方显示复制图标和本地时间，格式固定为 `yyyy.MM.dd HH:mm:ss`，例如 `2026.11.09 15:22:32`。时间在消息创建时记录，流式更新、暂停／继续和后续工具请求不会重置时间；该时间不作为模型上下文发送。只有实际记录过创建时间的消息才显示时间，不通过界面刷新时间补造历史时间。

复制按钮将原始正文写入剪贴板，保留 Markdown 标记、代码与换行；成功后短暂显示勾和本地化“已复制”提示。没有正文的失败回复可复制错误说明。助手正文使用 `SelectionArea` 支持跨段落选择，右键菜单通过 `AppTextSelectionMenu.buildRegion` 复用统一公共菜单；用户原文仍通过 `AppTextSelectionMenu.build` 接入。链接仅允许用户点击打开 HTTP、HTTPS 和邮件地址，打开失败显示本地化提示。

用户消息底部按“时间、复制按钮”排列，助手回复按“复制按钮、时间”排列。复制按钮静止底色与聊天背景一致，悬停使用 `interactionHoverColor(theme.secondary)` 从实际背景派生反向灰阶，浅色变深、深色变亮，避免固定悬停灰色融入页面。

代码围栏（包括 `text`、未指定语言和其他语言）显示独立圆角代码面板，顶部标注语言或本地化“纯文本”，右上角复制按钮只复制该代码块内容，保留缩进、尾部空格和换行，不包含围栏与语言标签。正文仍可通过统一选择区域选取，长代码行可横向滚动。行内反引号代码使用 4 px 圆角背景；`**加粗**` 仍按 Markdown 标准显示加粗文字。链接文字与下划线显式共用 `theme.basePrimary`，不从正文继承下划线颜色。

Windows 长消息选择需避免多个不必要的横向滚动选择容器：代码块按当前字体、缩放和可用宽度测量，能放下时直接加入消息的连续选区；超宽代码才使用横向滚动及独立 `SelectableText`，沿用紧贴文字的选区和统一右键菜单。超宽代码可单独选择／复制，跨越该独立编辑选区的拖选不保证连续，完整代码仍可通过代码块按钮复制。表格使用可用宽度分配列宽，不再为每张表添加横向滚动选择容器。回归覆盖 Windows 下滚动长回复后选择第二个代码块、表格，以及跨普通代码块选择。

聊天记录距离底部超过 120 px 时，在输入区右上方显示“回到最新消息”按钮；点击后平滑滚至底部，并在接近底部时隐藏。按钮随输入区实际高度定位，空会话不显示；系统关闭动画时直接跳转，不强制聚焦编辑器。

该按钮使用主题的 `iconBackgroundColor` 中性填充，悬停从实际按钮底色派生，保持明暗主题下与页面的区分。出现和收起仅使用 150 ms 透明度淡入／淡出，保持控件坐标和尺寸固定，不展开、不缩放、不平移；隐藏过程中立即退出鼠标、键盘和无障碍交互，系统减少动画时立即切换。

聊天记录和聊天编辑器统一使用 `AppScrollBehavior(scrollbars: false)`，只由各自外层绘制一根滚动条，仍保留全局 180 ms 鼠标滚轮平滑动画、连续滚轮目标累计和嵌套滚动仲裁。不能用 `copyWith(scrollbars: false)` 替代：Flutter 会跳过 `buildScrollbar`，连同平滑滚轮入口一起关闭。

## 透明图标按钮的悬停过渡

消息及代码块复制按钮复用 `TitleBarIconButton` 和 `InteractionDecoration`，保持共用的 150 ms 线性悬停动画和点击水波纹。透明静止背景必须使用悬停目标颜色的 RGB，并将 alpha 设为 0；进入和移出时只改变透明度。不要直接将透明黑 `Colors.transparent` 与不透明悬停色作为动画两端，否则 RGB 和 alpha 同时插值，叠加到页面后会短暂变暗，看起来像闪色。

调用方仍可传入 `Colors.transparent`，由共用按钮统一规范化。禁用和窗口失焦状态保持透明，不额外绘制圆形背景；切换主题立即更新配色，不播放旧主题颜色。系统减少动画时直接切换。回归测试须覆盖明暗主题的进入、移出中间帧，不能只检查动画起点和终点。

## 含图片消息的回到底部

聊天列表采用懒加载，不同高度的文字和图片消息进入视口时，`maxScrollExtent` 可能重新估算。“回到最新消息”不能只使用点击时的单次估算值：到达目标后等待布局更新，仍有剩余距离则继续校正，使用原有平滑动画；减少动画时直接定位后复查。校正须有次数上限，页面卸载、新的定位请求或用户中途取消滚动时结束，避免持续输出时无限追随或抢占用户滚动。回归覆盖混合高度图片消息、输入区带图片附件，以及开启／关闭动画时单次点击到达底部。

## 输入区多图附件预览

草稿附件位于双层输入框之间，缩略图为等边正方形，边长不超过 64 px，间距 8 px。扣除左右各 12 px 的对称内边距后，按 `列数 = ceil((可用宽度 + 8) / (64 + 8))`、`边长 = (可用宽度 - 8 × (列数 - 1)) / 列数` 计算，让完整行填满可用宽度；不足一行仍保持相同尺寸，不拉伸填充。附件区最大高度为两行图片、行间距和上下各 7 px 内边距之和；更多图片使用独立纵向滚动，支持共用平滑鼠标滚轮和可拖动滚动条。滚动条沿用全局显示／隐藏规则，不强制常显；滚动条位于右侧 12 px 留白内，不额外增加右边距，避免两侧留白不一致或覆盖图片及移除按钮。禁止仅用无滚动提示的单行横向列表裁切大量附件。附件高度变化保留扩展动画，系统减少动画时直接更新。

发送后的图片使用 120 × 120 px 正方形预览、8 px 圆角，按原比例完整缩放（`BoxFit.contain`），空余区域使用当前主题的 `secondary` 背景填充，不裁切截图内容；不与输入区最大 64 px 的附件缩略图共用尺寸。

## 原图预览

发送后的图片与输入区附件共用 `ImageClipboardMenu`：右键菜单提供“查看原图”和“复制图片”，双击缩略图也可打开原图。预览使用共享的 `showAppImageViewer`，按原比例完整展示原图字节，不使用缩略图作为预览数据。

遮罩沿用应用弹窗的 `DialogTheme.barrierColor`，未配置时使用 Flutter 标准的 `Colors.black54`。打开和关闭仅进行共用的 150 ms 透明度渐变，图片解码完成后淡入；系统减少动画时立即切换。右上角关闭按钮复用 `TitleBarIconButton` 和统一悬停提示。点击图片以外的区域、关闭按钮或按 Escape 退出；点击图片本身不关闭，拖动图片不触发关闭。

按住 Ctrl 并滚动鼠标滚轮，以鼠标位置为锚点缩放，范围为初始适配尺寸的 0.25～8 倍；普通滚轮不缩放。可拖动平移查看放大后的内容，每次重新打开恢复初始适配状态。相关按钮、菜单和加载失败提示使用本地化文案。
