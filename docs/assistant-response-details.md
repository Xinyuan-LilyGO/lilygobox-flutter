# AI 回复耗时与详情

每轮回复在正文顶部显示计时和分隔线：收到首段文字前显示“正在思考＋计时”，开始输出后切换为“用时＋计时”，完成后保留最终用时。不会在正文底部追加思考状态。点击耗时行可展开所用模型，以及助手在本轮实际执行的应用设置操作和结果。

详情仅基于客户端能验证的请求配置和设置工具调用记录，不展示或推测模型隐藏推理。普通问答显示本轮没有修改应用设置。

标准 SSE 响应按服务端增量逐步显示；若兼容服务忽略流式请求并返回完整 JSON，消息仍通过小段更新逐步显示。暂停会暂停网络接收和待显示文本，继续后接着显示。停止后保留已显示的部分文本。

计时在暂停时冻结、继续后累计。耗时覆盖用户发送到最终回复完成的全过程，包括助手发起的设置操作和后续模型请求。模型服务配置不会显示 API 密钥。
