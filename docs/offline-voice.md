# Windows 离线语音

语音功能在 Windows 上使用 sherpa-onnx 2.0.3 本地推理，与智能体使用的对话模型、角色卡和聊天记录相互独立。模型导入后，录音识别和朗读不需要联网；发送聊天仍使用已配置的模型服务。

## 模型和音色

打开「设置 → 智能体 → 语音 → 导入模型」，直接选择官方 `.tar.bz2` / `.tar.zst` 或本应用导出的模型包，不需要手动解包。上游单模型包的模型文件可在包的根目录或同一个子目录下。

语音页和角色卡库共用列表卡片。顶部提供「导出模型包」和「导入模型」，下方是带主标题和副标题的单列模型列表。卡片显示名称、用途与格式或不可用状态，以及绑定的智能体数量；统计包含回收站。合成模型的副标题还显示音色数量，例如「语音合成 · 中文 VITS · 5 种音色」。操作按钮靠右排列，窄窗口时换行。「查看详情」统一打开模型信息弹窗：合成模型可切换音色并试听；识别模型使用默认麦克风录音，边录边在输入框显示识别结果，停止后可编辑、复制。再次录音把结果追加到现有文字下方。测试不需要绑定智能体，不发送聊天消息，关闭弹窗会取消正在进行的录音或识别。

单击卡片可选中，Ctrl／Cmd 单击可增减选区，Shift 单击可连续选中。也可通过右键菜单或 Ctrl／Cmd+A 全选。点击「删除选中」或按 Delete 会打开同一个确认框，列出所选模型和受影响的智能体，包括回收站中和已暂停模型的智能体。确认后解除对应的语音绑定，保留聊天记录、其余语音绑定和原始压缩包。

| 用途 | 已在 Windows x64 验证的上游模型 | 所需文件 |
| --- | --- | --- |
| 中英双语识别 | [Streaming Zipformer 2023-02-20](https://github.com/k2-fsa/sherpa-onnx/releases/download/asr-models/sherpa-onnx-streaming-zipformer-bilingual-zh-en-2023-02-20.tar.bz2) | `encoder-epoch-99-avg-1.int8.onnx`、`decoder-epoch-99-avg-1.onnx`、`joiner-epoch-99-avg-1.int8.onnx`、`tokens.txt` |
| 中文合成 | [VITS vits-zh-ll](https://github.com/k2-fsa/sherpa-onnx/releases/download/tts-models/sherpa-onnx-vits-zh-ll.tar.bz2) | `model.onnx`、`lexicon.txt`、`tokens.txt`、`phone.fst`、`date.fst`、`number.fst` 和原始 `dict/` |
| 英文朗读和同句中英混读 | [Kokoro Multilingual v1.0](https://github.com/k2-fsa/sherpa-onnx/releases/download/tts-models/kokoro-multi-lang-v1_0.tar.bz2) | `model.onnx`、`voices.bin`、`tokens.txt`、`lexicon-us-en.txt`、`lexicon-zh.txt`、`phone-zh.fst`、`date-zh.fst`、`number-zh.fst` 和原始 `espeak-ng-data/` |

应用只安装所需文件，保持模型内部路径；上游模型不需要额外清单。模型按文件内容去重，修改文件名不影响去重。导入只加入模型库，不会自动绑定智能体。试听音色只在当前弹窗生效。对内容指纹匹配的 `vits-zh-ll` 与 `kokoro-multi-lang-v1_0`，界面按上游的音色 ID 顺序显示原始名称；未核验映射的模型只显示编号。已有智能体保存的音色 ID 不变。

要朗读英文或中英混合回复，在设置中导入 `kokoro-multi-lang-v1_0.tar.bz2`，然后在聊天右上角的「语音合成」为当前智能体选择 Kokoro。模型库详情中的「试听」会播放中英混读示例。

点击「导出模型包」打开与角色卡库同款的选择弹窗。可用模型默认全选，点击卡片可取消选择。确认后将所选模型保存为 `lilygobox-voice-model-package-YYYYMMDDHHmm.tar.zst`。包内保留原始推理文件和各模型的名称、格式，不包括音色设置或智能体绑定。重新导入组合包时会跳过已经安装的完整模型。`.tar.bz2` 仅支持导入。压缩在后台分块执行，单个模型最多 512 MiB，整个压缩包和展开的 TAR 均不得超过 1 GiB。

导入和导出复用智能体数据包的进度弹窗。弹窗显示当前阶段、已用时间及可测量的阶段进度。最终保存前可取消，后台退出后清理临时文件，不修改已安装的模型和已有导出文件；最终落盘阶段不可取消。

删除只移除语音库中的副本，不修改原始压缩包。依赖该模型的语音功能停止，也不会自动改用其他模型。缺文件的模型会标记为不可用，重新导入原包可修复。仅导入来自可信来源的模型。

「设置 → 存储」的占用图单列统计本机保存的语音模型文件，并将它们计入总量。导入期间的临时文件和外部压缩包不计入；点击「刷新」可重新统计。

## 聊天使用

- 聊天右上角在角色卡左侧分别提供语音合成和语音识别入口，无论是否启用或绑定，均使用扬声器与麦克风图标，并独立打开对应的模型列表。浮层与角色卡同宽，可搜索当前类型的模型。点击模型卡立即绑定并进入详情。详情的启用开关分别控制朗读和录音识别，关闭时保留模型和音色设定。选择「不使用」解除对应类型。从详情返回保留该类型列表。聊天模型详情和「语音合成设置」使用与模型库一致的副标题。「语音合成设置」沿用角色卡设定的布局，在模型信息下显示音色说明和选择控件，按智能体独立保存。
- 悬停每个语音入口会显示其用途和已绑定模型的完整名称；折叠到纯图标时也可查看。打开另一个语音入口时，当前浮层会自动收起。
- 绑定识别模型后，聊天输入框出现麦克风图标。录音期间识别器在后台持续处理音频；点击停止后，最终转写才追加到当前草稿，并可编辑后手动发送。软件使用默认麦克风，最长一段 90 秒，离开会话会取消录音或仍在运行的识别。
- 合成模型可用时，已结束的 AI 正文旁出现朗读按钮。点击播放，再点停止。播放使用 Windows 默认输出设备，不读取模型思考、工具过程、代码块或错误详情，也不会自动朗读。
- 录音、转写和播放故障会提示，不会阻断普通文字输入和发送。录音和生成音频不写入文件，也不随聊天导出。

## 验证

独立验证程序位于 `tool/speech_probe`。在该目录执行 `flutter pub get` 后运行：

```powershell
dart run bin/speech_probe.dart <DLL目录> <识别模型目录> <输入WAV> <合成模型目录> <输出WAV> '是不是频繁的'
```

DLL 目录为对应架构的 `sherpa_onnx_windows` 插件目录，例如 Pub 缓存中 `sherpa_onnx_windows-2.0.3/windows/x64`。使用识别包内 `test_wavs/2.wav` 可校验上面的预期词。验证程序写出 WAV 供人工试听，正式应用不落盘。应用子进程使用随应用打包的 ONNX Runtime，先从可执行文件所在目录加载，避免误用系统目录中的旧版本。

实机验收时完整停止旧的 `flutter run`，用 `flutter run -d windows` 重启。导入模型并试听后，打开聊天的「语音」浮层，分别选择合成和识别模型。在聊天点麦克风说一句中文，确认识别结果进入可编辑的草稿，手动发送后点击回复的朗读按钮，确认听到回复并验证停止按钮。

若录不到声音，先在「Windows 设置 → 系统 → 声音 → 输入」确认有默认麦克风，并确认说话时输入音量有变化，再检查「隐私和安全性 → 麦克风」是否允许桌面应用访问。若听不到声音，检查默认输出设备及应用音量。文件推理、原生播放完成事件和聊天控件测试均不替代这次实机验收。
