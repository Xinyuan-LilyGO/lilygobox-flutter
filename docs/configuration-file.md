# 配置文件导入与导出

在 LilygoBox 的“设置 → 通用”中，可以导出当前外观与布局配置，或从 JSON 配置文件导入设置。

## 导出配置

1. 打开“设置 → 通用”。
2. 选择“导出配置”。
3. 在系统文件对话框中选择保存位置。

配置文件使用 JSON 格式，默认文件名为 `lilygobox-config.json`。

## 导入配置

1. 打开“设置 → 通用”。
2. 选择“导入配置”，并选择 LilygoBox JSON 配置文件。
3. 确认提示后，文件中的配置会覆盖当前配置。

导入前会检查文件格式、配置版本和字段取值。无法识别或超出有效范围的配置不会应用。

## 配置范围

配置文件包含主题、语言、字体、主页侧边栏状态与宽度、内容分栏宽度和设置侧边栏宽度。账号凭据、设备配对信息和固件缓存不会导出，也不会因导入而更改。
