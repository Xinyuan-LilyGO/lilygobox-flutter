# 配置文件导入与导出

在 LilygoBox 的“设置 → 通用”中，可以导出当前外观与布局配置，或从 JSON 配置文件导入设置。

## 导出配置

1. 打开“设置 → 通用”。
2. 选择“导出配置”。
3. 在系统文件对话框中选择保存位置。

配置文件使用 JSON 格式，默认文件名为 `lilygobox-config.json`。

## 导入配置

1. 打开“设置 → 通用”。
2. 选择“导入配置”，并选择 LilygoBox JSON 配置文件。
3. 确认提示后，文件中的配置会覆盖当前配置。

导入前会检查文件格式、配置版本和字段取值。无法识别或超出有效范围的配置不会应用。

## 配置范围

配置文件包含主题、语言、字体、主页侧边栏状态与宽度、内容分栏宽度和设置侧边栏宽度。账号凭据、设备配对信息和固件缓存不会导出，也不会因导入而更改。

## 模型服务配置

“设置 → 模型服务”提供独立的“导出配置”和“导入配置”，默认文件名为 `lilygobox-model-services.json`，与通用配置文件分开。页面明确提示文件包含明文 API 密钥，需妥善保管。

导出默认包含全部服务、API 地址与协议、模型列表及图片能力声明、所选服务与模型、思考强度和 API 密钥。密钥在应用运行时从已加载的系统安全存储配置读取，导出的 JSON 文件本身不加密。导入后密钥写入目标系统的安全存储，不写入普通偏好配置。

导入需要确认：相同服务 ID 的配置和密钥更新，新服务追加，其余服务保留；重复导入同一文件不会重复添加服务。不同服务 ID 即使名称相同仍视为不同服务。导入会恢复备份中的有效模型选择。

模型配置使用独立的格式标识与版本。导入先完整校验，再写入；格式或版本不支持、字段不合法、文件超过 2 MiB 或 UTF-8 无效时不应用。写入失败会尝试回滚密钥与配置。取消文件选择或确认均不更改服务。模型配置不包含聊天记录、会话授权、命令策略或通用界面设置。
