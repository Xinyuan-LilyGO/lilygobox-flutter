# Dart 文件头注释

`lib/` 下新增的 Dart 源文件在第一行使用统一文件头，字段顺序、缩进和结束符保持一致：

```dart
/*
 * @Description: 用中文简要说明本文件职责。
 * @Author: LILYGO_L
 * @Date: 2026-11-04 09:36:57
 * @LastEditTime: 2026-11-04 09:36:57
 * @License: GPL 3.0
 */
```

- `@Description` 使用中文，描述文件职责，不复述文件名。
- `@Author` 记录实际作者；已有文件保留原作者，不因后续修改而改写。
- `@Date` 记录文件创建时间；修改已有文件时保留原值。
- `@LastEditTime` 在修改文件时更新为实际修改时间，不复制示例时间。
- `@License` 沿用项目许可证。
- 注释紧贴文件开头，不在结束符后添加额外装饰。

示例中的作者和时间只展示格式。新增文件应记录实际作者和时间；无法确认的信息不要伪造。
