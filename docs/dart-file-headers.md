# Dart 文件头注释

`lib/` 下新增的 Dart 源文件在第一行使用统一文件头，以 `@Description` 简要说明文件职责：

```dart
/*
 * @Description: 用中文简要说明本文件职责。
 */
```

- `@Description` 使用中文，描述文件职责，不复述文件名。
- 新增或修改的说明性注释、文档注释统一使用中文；类名、API 名、协议字段及必要的技术标识保持原样。生成器自动生成的说明和分析器指令不手动翻译。
- 文件头的缩进和结束符与示例保持一致，注释紧贴文件开头，不在结束符后添加额外装饰。
- 本地化等生成文件使用相同的文件头格式，在对应生成配置中统一维护。
- 项目许可证以仓库根目录 `LICENSE` 为准；第三方版权、许可证及 SPDX 声明按原样保留。
