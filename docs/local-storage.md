# 本地配置与页面状态

应用启动前读取普通配置，设置变更后自动保存，不需要手动保存按钮。

## 保存位置

Windows 使用当前用户的应用数据目录，由 `shared_preferences` 和系统目录 API 定位：

```text
%APPDATA%\LILYGO\LilygoBox\shared_preferences.json
```

配置位于插件管理的文件中，使用 `lilygobox.preferences.v1` 作为逻辑键。软件移动或更新后，只要应用的公司名和产品名保持不变，就继续使用同一份配置。Android 使用应用私有存储，不依赖安装文件夹。

## 保存内容

- 主题与界面语言。
- 主侧栏宽度与显示状态。
- 设置侧栏宽度、设备页面左右分栏宽度。
- 已添加设备的标识、名称、型号和局域网连接地址。

设备记录用于恢复列表，在线状态由实际连接和心跳判断，不写入普通配置。GitHub 登录凭证和设备配对密钥由系统安全存储管理，不写入普通配置。

没有已保存的配置时，应用使用默认设置。

## 保存与恢复

启动时先读取配置再显示应用，避免短暂显示默认主题或语言。连续修改按顺序合并写入；正常关闭 Windows 窗口前等待待保存内容完成。保存失败时显示提示，可重试或选择不保存并退出。进程被强制终止、断电等情况仍可能丢失尚未完成的写入。

无法解析配置时使用默认值并显示提示，不自动覆盖原配置。遇到该提示应检查文件内容、磁盘空间及目录权限。恢复默认设置会保存默认主题、语言和侧栏布局，保留账号及设备列表。

## 页面保留

打开应用设置或设备设置时，原页面保留在覆盖页下方，关闭设置返回进入前的页面。已访问的设备页面和设备子页面在本次运行中保留状态；隐藏页面不接收键盘焦点，并暂停界面动画。正在进行的发现与连接异步任务可以继续更新其页面状态。

明确离开添加设备流程时，会释放该页面并取消未完成的操作。关闭整个应用后，运行中的页面和连接任务不会从磁盘复活；下次启动进入主页并加载普通配置。
