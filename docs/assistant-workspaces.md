# 主页智能体工作流

## 入口与拓扑

画布顶部不再使用整行标题栏：左上角独立显示点阵图标和“智能体工作流”标题，使用与底部说明栏相同的主题背景色，外形为 8px 小圆角长方形，内部左右留白 12px、上下 10px；操作使用顶部居中的悬浮胶囊工具条，以画布视口而非整个应用窗口为中心。工具条复用公共 MenuItemSurface、主题表面色和卡片阴影，创建主智能体、添加子智能体和删除始终显示；没有适用选择时置灰禁用，选中一个可作为上级的智能体后启用添加子智能体，选中智能体后启用删除，不因选中变化增减按钮或改变工具条宽度。悬停使用与右键菜单一致的主题紫色和 onPrimary 文字／图标，选中及点击反馈由同一公共菜单组件管理，禁用项没有悬停或点击反馈。布局尺寸变化采用 180ms 过渡，减少动画模式直接切换。根据当前语言、文字缩放和操作内容测量所需宽度；空间不足时将工具条放到标题下方居中，按钮必要时换行，保持至少 16px 左右边距。工具条不随画布平移、缩放，底部视图工具栏维持原有布局。

主页直接显示智能体拓扑，不新增全局侧栏页面。空白工作流提供“创建主智能体”入口；顶部工具按钮常驻，只有选中适用智能体时启用对应操作；主智能体由用户手动创建，可创建多个互相独立的主智能体。主智能体和子智能体显示为连接卡片，分别持有独立对话，卡片显示名称、执行模型、智能体类型、智能体 ID 和当前状态。智能体 ID 使用会话注册表原始标识，卡片和智能体详情顶部均显示完整值，不截取尾部、不以省略号截断；宽度不足时自然换行，并计入卡片自适应高度，右键复制始终复制完整 ID。智能体类型与状态图标使用 fill 样式。主智能体与子智能体的类型标题在卡片和详情顶部统一使用 12px、w600，类型图标统一为 18px，卡片高度测量同步采用该规格。画布支持平移、缩放、拖动节点与重置视图。底部工具栏可选择点阵、网格或纯色背景，默认点阵；背景按钮左键按点阵、网格、纯色循环切换，右键打开公共选择菜单，按钮及菜单为三种样式使用不同图标。偏好独立保存于 ai.agentCanvasStyle.v1，不包含智能体授权。节点手势提供的局部拖动距离不重复除以画布缩放比例，保证缩小或放大后仍跟随鼠标。工具条及画布菜单的放大、缩小，以及手动重置视图，使用 200ms、Curves.easeInOut 的位置与缩放插值过渡，手动操作可打断；减少动画模式和首次自动布局直接定位。节点右键菜单复用公共 RightClickMenuBuilder 模板，提供打开对话、添加下级子智能体、复制智能体 ID、停止执行和删除智能体；打开对话、复制 ID 和添加下级作用于右键智能体，停止、断开和删除作用于当前选择组。

“主智能体”表示一棵智能体树的起点；“子智能体”表示可持续沟通和管理的下级智能体。所有手动创建和模型分派的子智能体统一使用同一类型，立即显示在智能体拓扑中，主智能体与子智能体都能继续分派下级，不固定层数；用户可以打开任意智能体继续对话、补充要求、停止或删除。“用时”仅记录创建、等待、发送消息及删除等操作，不提供子智能体专用跳转接口；进入智能体统一通过工作流卡片。删除子智能体时递归停止并删除其下级智能体，其他分支保留。删除主智能体时保留子智能体分支，将最后创建的直属子智能体提升为主智能体，其余直属子智能体分支连接到它下面；没有子智能体可提升时只移除原主智能体。提升保留原智能体 ID、对话、模型和权限，不重置自动消息额度。

用户删除沿用公共确认框和画布撤销／重做规则。模型可以通过 stop_agent 停止自己的直属子智能体，或通过 delete_agent 删除自己的直属子智能体及其下级；不能删除自身、上级或仅通过沟通连线相连的其他智能体。删除会停止生成、取消批准和提问、终止并清理所属进程，再移除卡片与连接。若用户撤销历史仍引用被删除智能体，已停止的会话只为恢复保留，历史引用释放后销毁。已完成智能体不会仅因完成状态就自动销毁或从工作流消失，需由用户或所属智能体明确删除。

拓扑保留单上级的智能体归属树，并允许另外建立双向沟通连接。创建子智能体形成的归属连线与手动添加的沟通连线统一显示；同一归属树内的子智能体互连不会替换原有上级或改变智能体类型。连接不同智能体树时，必须先通过公共确认框说明归属调整：终点为子智能体时，只将终点及其下级从原上级迁移到起点下面，原树主智能体及其他分支保留；终点为主智能体时，整棵目标树迁移，目标主智能体改为子智能体。迁移分支的聊天与内部连接保留，跨分支沟通连接断开。取消不添加连线、不改变任何关系。直接相连的智能体可通过协作工具相互查看状态和发送消息；未连接的智能体仍不可访问彼此。沟通连接允许形成环，但上级归属仍禁止循环和多上级。连线仅根据两端卡片位置选择端点并绘制平滑贝塞尔曲线，限制控制点避免回绕，不添加方向箭头；其他卡片和连线不参与避障或分流，线条绘制在卡片下方，由卡片自然遮挡。

画布可以持续向各方向平移，渲染场景按卡片位置动态扩展；卡片向左上跨过场景原点时统一重置内部坐标并反向补偿视图，保持鼠标下的位置连续，不限制拖动方向。视口边缘正常裁剪画布，卡片不会溢出盖住侧栏。底部说明与视图工具使用独立工具栏，不能悬浮遮挡可操作的卡片。视图缩放存在下限，智能体很多时不能保证全部同时出现在窗口内，仍需平移浏览。智能体总数与子智能体同时运行数量不设固定上限，实际承载能力取决于本机资源和模型服务；创建、复制、消息投递及输入框发送不因其他智能体正在运行而拒绝。

“自动布局”清除当前页面的手动卡片位置，按智能体树重新排列并以 200ms 动画调整视角；“重置视图”只调整位置与缩放，不改变卡片排列。两者在底部工具栏中提供独立入口，减少动画模式下直接定位。工具栏保留主题长条背景，内部统一使用 24px 纯图标按钮（内部图标保持 17px）和 4px 方形圆角；外层与右键菜单一致，圆角为 8px、内边距为 5px，按钮之间间距为 4px；功能名称只在悬停提示和无障碍标签中显示。按钮复用公共 MenuItemSurface，与右键菜单使用相同的主题紫色悬停反馈和选中配色，不使用圆形按钮背景。

## 卡片与画布编辑

卡片选中边框沿用聊天输入框：1px 主题紫色与透明色之间以 180ms、Curves.easeOut 过渡，减少动画模式直接切换；边框绘制在前景，不改变内容尺寸和布局。卡片宽度固定为 252px，最小高度 164px，名称按完整内容自然换行并自动增加卡片高度，不截断、不使用内部滚动条；文字缩放时同步适配。卡片高度按实际文字样式、缩放、方向和语言测量，连线、连接点、框选、命中区域、场景边界与自动布局统一使用各卡片的实际尺寸。重命名保持卡片左上角和当前视角，自动布局按新高度重新排列。单击选中、双击打开、节点数量变化及窗口/工具区尺寸变化均不触发自动居中；只在初次呈现画布或空画布首次加入智能体时自动定位，其后由“重置视图”或“自动布局”主动调整。智能体对话顶部名称仍最多显示约两行高度，超出后独立纵向滚动，保留完整名称；只绘制一份滚动条，距名称区域右边缘及上下两端 6px，文字右侧预留 20px。返回按钮保持稳定，不被长名称撑开；智能体类型、服务与模型、完整智能体 ID 放在顶部右侧并右对齐，使用无背景、无边框的文字布局，智能体类型左侧使用对应 fill 图标。名称放在左侧可用区域，长名称换行并保持限高滚动，滚动条不常驻。卡片智能体 ID 上方显示“服务分组名 · 模型名”，分组沿用选择模型菜单的 service.name；找不到服务时仅显示模型名，单行溢出省略并提供完整悬停提示。

卡片主体仅使用公共 CardShadow 阴影，不使用 TiltCard 倾斜或重力效果，默认无描边，不添加按压填色或点击波纹。仅选中时显示主题紫色边框；卡片主体、连接点和选中边框均保持稳定坐标。工作中的智能体在右上角显示状态灯，等待批准或回答使用对应提示状态。

单击选中，点击另一张卡片替换选中，Ctrl / Shift 点击增减选择；空白处点击清空选择，由框选同一条指针松开路径提交，不依赖框选覆盖层重建期间的 Tap 识别。空白处右键同样清空卡片选中并关闭卡片菜单，弹出公共画布菜单，提供缩小、放大、自动布局、三种背景选择及重置视图；右键连线仍提供断开操作，断开前弹窗确认，按剩余连接自动调整主智能体与子智能体，保留名称、ID、模型、权限及历史；右键拖动只平移、不弹菜单；普通左键拖动空白处框选，Ctrl / Shift 拖动保留原选区；框选使用主题紫色外框与 8% 透明填充，作为不接收指针事件的最上层覆盖在所有卡片之上，拖动期间屏蔽卡片与创建入口的悬停、点击和拖动，松手后才提交选区；右键拖动超过手势阈值后平移，右键单击仍打开原有菜单，拖动松手不弹菜单。Ctrl 加滚轮以鼠标位置为中心平滑缩放，使用 200ms、Curves.easeOut 过渡，首次操作不要求预先聚焦画布；连续同向滚轮累计目标比例并从当前画面重新衔接，反向时从当前比例响应，避免动画重启丢失缩放量。鼠标拖动、其他视图操作可打断，减少动画模式直接定位；普通滚轮上下平移画布，Shift 加滚轮左右平移，Ctrl 优先用于缩放；滚轮平移同样使用 200ms、Curves.easeOut 动画，连续同向滚动累加目标位移，反向从当前画面响应，减少动画模式直接定位。Space 加左键和鼠标中键保留为辅助平移方式，画布快捷键不能接管输入框的空格。滚轮处理限定在画布内部，不接管聊天或弹出菜单的滚动。选中的卡片可共同拖动，右键已选卡片保留整组选中，右键未选卡片改为选中该卡片。批量菜单复用公共右键模板。画布获得焦点时支持全选、Delete、Ctrl/Cmd+C 和 Ctrl/Cmd+V，不能劫持搜索、智能体名称、聊天等输入框的编辑快捷键。复制保存所选卡片的名称、完整工作内容、服务与模型、思考强度及权限快照；粘贴按会话分支创建新 ID 的独立副本，继承复制时的聊天、图片附件、操作展示记录与模型上下文，不复制未选中的下级。多选一起复制时保留选中节点之间的归属连接与额外沟通连接，不把副本自动接回未选中的沟通对象。系统剪贴板仅写入应用内识别标记，内容快照保留在当前工作流页面内存，不包含密钥；剪贴板被其他内容覆盖后不粘贴旧卡片。每次粘贴相对复制位置递增偏移 40px。

同树拖动连接点只新增沟通连接；跨树连接先确认归属调整，确认前不修改任何智能体或连线。终点为子智能体时仅迁移该子智能体及其下级：断开原上级后接到起点，原树的主智能体与其他分支保留；终点为主智能体时才迁移整棵目标树并将目标主智能体改为子智能体。跨出迁移分支的沟通连接同时断开，内部连接保留。整个调整为一个可撤销步骤，取消不变。确认计划包含两端所属树与智能体类型，确认期间关系变化时重新提示。重复或反向连接同一对智能体不产生重复连线；不允许自连、已关闭智能体参与。点击、框选与右键菜单同时支持两类连线。断开连接前统一显示确认框，并列出主智能体／子智能体的变化。确认后按剩余连通关系调整角色：独立出来的智能体组保留一个主智能体，其余节点为子智能体；存在其他沟通路径时继续保留同一智能体组。取消不修改连线或角色。卡片菜单的“断开连接”断开所选智能体关联的全部连线，保留对话与智能体。跨树合并和明确的角色菜单操作可以调整上级；普通同树连线不能替换已有上级，连线不作为权限授予。恰好选中两张尚未直接连接的卡片时，右键显示“连接所选智能体”，以右键卡片为起点，复用拖线及合并确认流程；已直接连接时隐藏该项。

右键子智能体可“设为主智能体”，先通过公共确认框说明类型变化，确认后断开子树与原智能体组之间的父连接及外部沟通连接，保留子树内部连接和完整下级；右键主智能体可“设为子智能体”，通过公共标准弹窗和下拉菜单选择合法上级。角色切换只操作当前右键卡片，不批量套用到选择组。右键“重命名”使用公共标准弹窗，名称限 1–200 个字符，去除首尾空白，取消不改变智能体；名称同步更新卡片和对话标题，不修改 ID 或其他智能体信息。上级候选排除自身、所有后代、已关闭智能体；没有合法候选时隐藏入口。右键“置于顶层”只调整当前卡片在页面中的叠放顺序，不改变连接、模型或智能体关系；选框覆盖层始终高于所有卡片。显示层级仅在当前页面保留。右键“复制卡片”复制当前智能体完整名称、工作内容、模型、思考强度和权限；名称使用递增数字后缀，如“名称 (2)”“名称 (3)”，复制已有编号的智能体时继续递增且跳过已用名称，不叠加后缀；数字后缀超过 200 字限制时保留完整原名，不截字；新建独立 ID，沿用原智能体类型及上级，继承复制时的对话历史、图片附件、操作展示记录和完整模型上下文，两边后续对话互不影响；不复制下级、活动进程、待批准或待回答状态，不自动执行。未完成工具调用在副本上下文中记录为取消，不重放操作。已有对话的副本输入框留空；尚未开始的智能体保留原智能体草稿。副本放在原位置右下 40px，创建后选中而不自动打开对话。

角色改变保留原智能体 ID、对话、模型、权限与手动位置；提升为独立主智能体时清除子树边界上的外部连接，内部沟通连接保留；沿用归属树的循环校验。所有需要改变角色的界面操作必须先显示公共标准确认／选择弹窗；删除主智能体时，在删除确认框中明确列出将由子智能体变为主智能体的智能体名称。确认期间接任候选改变时重新确认，不静默改变新的智能体角色。

拆分或合并智能体树时保守保留自动通信额度和去重记录，不能通过断开、重新连接重置额度。同树内移动不重复累计。批量删除先确定明确选中的子智能体分支，再处理主智能体接任，避免把已明确要求删除的智能体重新提升保留；祖孙重复选择只释放一次。

交互参考：[React Flow 基础交互](https://reactflow.dev/learn/concepts/adding-interactivity)、[连线重接](https://reactflow.dev/examples/edges/reconnect-edge)、[连接验证](https://reactflow.dev/examples/interaction/validation)、[Blender 节点编辑](https://docs.blender.org/manual/en/latest/interface/controls/nodes/editing.html)。本项目以单上级归属树管理智能体生命周期，额外的无向沟通连接只提供直接相邻智能体的通信能力，不将连线解释为文件权限授予。

## 会话与协作

双击节点或使用“打开对话”在主页内部打开完整会话，返回工作流仍保留页面状态。返回入口沿用设备页面的圆形 TitleBarIconButton：28px 按钮、18px 箭头，旁边显示智能体标题，只有按钮本身触发返回。会话复用主聊天的流式回复、用时详情、文件/网页/命令工具、批准卡片与提问卡片；稳定智能体 ID 和公共保留页面容器用于保存草稿、滚动位置与焦点隔离，页面采用公共淡入动画。所有主智能体和子智能体均提供普通输入框，可由用户继续对话。

| 工具 | 用途 |
| --- | --- |
| `list_agent_models` | 查询已配置且具有密钥的服务名称、服务 ID 与准确模型 ID，不返回密钥或端点 |
| `spawn_agent` | 创建可见的直接下级子智能体，不提供 kind 参数；可指定 service_id 与 model，立即返回智能体 ID 及实际模型 |
| `list_agents` | 查询相连智能体的状态和可用结果 |
| `send_agent_message` | 向相连智能体投递消息 |
| `wait_agents` | 有界等待后返回当前状态和结果 |
| `stop_agent` | 停止当前智能体的直属子智能体，保留其卡片和对话 |
| `delete_agent` | 删除当前智能体的直属子智能体及其下级，停止并清理运行资源 |

各智能体独立持有聊天历史、请求取消信号、HTTP 响应订阅、进程会话、批准与提问状态。创建子智能体默认只传工作内容，不复制主智能体完整历史；分派内容应包含目标和必要上下文。消息记录标明来源智能体，不把智能体之间的消息伪装成用户输入。消息投递不能绕过待批准、待回答状态。同一主智能体下整棵智能体树共享 12 次自动消息额度，相同来源、目标与正文的重复投递被抑制，实际人工输入后重置额度。接收消息后是否回信由模型决定，执行层不生成自动回信。

主智能体和子智能体均可独立运行，不设固定并发名额；后续请求沿用该智能体上下文。查询结果返回最近一段非空回复，超过 16,000 字符时截断并标记。等待工具有时间上限，停止等待不等于停止子智能体。执行结果不会直接插入另一会话正文，需要通过消息或查询取得。

## 模型与权限

用户创建主智能体或子智能体时可选择已配置的服务和模型；新智能体默认继承直接上级的选择，主智能体默认沿用当前服务。子智能体可使用其他已配置服务的模型；未指定时继承所属智能体的模型配置。每个智能体持有独立模型配置，调整其模型不覆盖其他智能体。端点与密钥成对保存在会话内存快照，避免服务编辑后旧端点收到新密钥；密钥不进入智能体工具参数或智能体持久记录。删除共享服务不等于撤销已运行会话中的旧内存快照，需要停止对应智能体或明确重新选择模型。

对话分派时先通过 `list_agent_models` 查询真实配置，再向 `spawn_agent` 同时传入准确的 `service_id` 与 `model`。两个参数必须同时指定或同时省略；只指定一个、服务不可用或模型不属于该服务时拒绝创建，不使用相似名称匹配或默认模型兜底。名称存在歧义时，工具说明要求通过现有 `request_user_input` 提问确认；语义理解由模型完成，执行层负责校验准确 ID。服务列表不暴露密钥或地址；创建与查询结果返回 `service_id`、`service_name` 和实际 `model`。目标服务和模型在首次请求前设置，独立使用该服务的协议、端点、凭据及已保存的模型强度配置。此流程只选择已有服务，不创建服务、不修改全局模型，也不提升继承的权限。

例如：“创建子智能体，用某服务的 DeepSeek 检查代码，之后我单独沟通”，或“派 GPT 模型核对结果，完成后汇报”。无论工作时长或用途，均创建可见、可手动管理的子智能体，采用相同的模型选择和权限规则。

智能体创建、重命名及选择上级弹窗的表单字段统一采用编辑服务样式：主标签使用 `AppDialogStyle.fieldTitleStyle`，下方 4px 显示 `descriptionStyle` 简短说明，再留 8px 放置控件。智能体名称、执行模型、权限、工作内容及上级选择都需提供对应说明，不以窗口顶部介绍替代字段说明。

创建时智能体名称可选；留空则由该智能体所选服务与模型独立生成简短名称，不提供执行工具，不写入智能体对话或历史。创建不等待命名请求：先从工作内容截取简短摘要，立即显示卡片并开始执行，后台命名成功后更新名称。命名请求最多等待 20 秒，失败、超时或无效输出时保留摘要；用户在等待期间手动改名后不覆盖，删除智能体时取消命名请求。用户明确填写的名称不额外请求、不被覆盖；重命名仍要求非空。模型工具 `spawn_agent` 的 title 同样可省略，工作内容必填。

创建窗口的执行模型菜单复用聊天区的选择模型组件，使用相同的搜索、服务分组、选中样式和滚动规则；只有创建子智能体时保留“继承上级模型”选项；主智能体没有上级，直接显示当前选中的实际服务与模型，并可自行切换。字段按钮使用设备卡片同款 Symbols.blur_on 点阵图标。模型选择下方复用聊天区的权限菜单及自定义权限页面。创建弹窗内两者使用相同的紧凑图标文字按钮、下拉控件背景及 4px 圆角；菜单在按钮下方 8px 处左对齐展开，收起时箭头向右，展开时向下。此窗口模式不改变主聊天的按钮与菜单定位。创建前的配置只存于窗口内的独立草稿，取消不改变上级或全局配置，确认后在首轮执行前应用于新智能体。

新智能体默认继承创建时上级权限，用户可在创建窗口明确调整；模型分派仍只能继承上级权限，不能通过创建参数提升权限。文件、命令、网页调用继续由执行层检查，危险命令与 forbidden 规则沿用公共实现。批准和提问属于发起操作的会话，不能由另一个智能体代替用户批准。并发智能体不具备文件冲突隔离；内置写文件保留 expected_content 校验，命令行修改仍需合理划分智能体范围。本功能不创建 Git 工作树或操作系统沙箱。

## 本地保存与恢复

智能体注册表使用独立的 `ai.agentWorkflow.v2` 存储键，保留主智能体、子智能体记录、归属关系、额外沟通连接、模型选择和对话文本。不限制节点或连接总数，也不再对完整注册表施加 2 MiB 的固定大小限制，避免大量节点可以创建却无法保存或恢复；每个会话仍最多保存最近 200 条文字消息，每条最多 100,000 字符。多层智能体按子树递归布局，场景随位置扩大。图上手动拖动的位置只在当前页面生命周期内保留，重启后重新自动布局。

恢复按父子依赖建立智能体树，不依赖记录排列顺序；损坏、环状或缺少上级的记录不能静默覆盖原保存。

复制时完整分支快照仅在当前运行会话内保留；应用重启仍遵循以下既有的文本记忆恢复范围。

恢复属于“文本记忆恢复”：恢复用户与助手正文，不重放工具协议、完整用时过程、进程、待批准或待回答对象，也不会自动执行智能体。智能体权限恢复为默认权限，需重新授权。服务被删除、模型不存在或密钥暂不可用时，保留节点和历史并禁用发送，用户重新选择可用模型后才能继续；不能静默换用别的模型。

智能体记录与模型服务配置的导入导出分开；智能体保存不包含密钥。保存失败保留原有存储，不使用不完整结果覆盖原记录。

框选同时支持卡片和连线，按连线路径与选框相交判断，松开鼠标才提交选中。Ctrl / Shift 框选累加原选区，连线使用主题紫色高亮；Delete 或连线右键菜单可一次断开选中的多条连线，保留聊天，并在确认后根据剩余连接自动调整智能体类型。

普通右键菜单以鼠标位置处理上下／左右边界，溢出时相对鼠标翻转，不相对整张卡片翻转，四周至少保留 8px。画布开始新一轮点击或拖动时关闭已有菜单，右键拖动松手不重开菜单。连线单击、Ctrl / Shift 增减选中、空白处取消与卡片一致；左键按下时不显示选框，拖动超过 4 个屏幕像素后才显示并进入框选，轻微抖动仍按单击处理，不随画布缩放放大抖动。已打开菜单区域的右键拖动同样关闭菜单并转交画布平移，不能残留浮层或在松手时重开。

混合选中卡片与连线后删除时，确认前不得断开任何连线或改变归属。取消保留全部节点、边和选区；确认后先按原归属执行节点删除／接任，再移除其余明确选中的连线，避免提前断线改变删除范围。Ctrl/Cmd+A 同时选中全部可见卡片与连线。

自动布局同时考虑归属与沟通连接，将连通分量分层、同层分支错开，按实际卡片尺寸留出间距。普通归属树沿用原有布局；额外沟通连接参与分层，不将孤立沟通链全部堆在同一轴线上。连线路径仅由两端卡片决定，不因第三方卡片或其他连线变动而绕行、偏移；绘制、单击命中和框选必须共用同一份路径缓存。手动移动保持原位置，自动布局由用户明确触发。

智能体详情右上角只展示智能体类型及完整智能体 ID，模型服务与模型名称在下方输入区展示，避免重复。设为主智能体的菜单图标与主智能体卡片统一使用 fill 的 hub 图标。

## 工作流撤销与重做

画布获得主焦点时，Ctrl/Cmd+Z 撤销一步，Ctrl/Cmd+Y 或 Ctrl/Cmd+Shift+Z 重做一步。智能体移动以一次完整拖动为一步；自动布局、置于顶层、创建、复制／粘贴、重命名、连接／断开、角色调整和删除均作为独立步骤。确认框取消或未发生修改时不记录；撤销后进行新编辑会清空重做分支。保留最近 30 步，离开该页面生命周期后释放历史。

撤销恢复原智能体 ID、连接、角色及卡片位置，删除智能体的聊天上下文保留以支持恢复；恢复不会重放命令、重新发送消息或重启已停止操作，也不回退聊天正文、权限批准及自动通信额度。输入框和对话内的撤销／重做由文本编辑器处理，画布不得拦截。平移、缩放和单纯选择不单独计入编辑步骤。

拖线预览根据鼠标相对起点的主方向选择水平或垂直控制点，并按正负方向调整弯曲；控制点位于两端之间，反向拖动不能出现越过端点的回钩。该预览只绘制待建立连接，实际连接规则及已有连线路由不受影响。

执行模型与权限作为表单字段时，展开箭头统一使用 expand_more，关闭时向右、展开时向下，沿用相同的线性旋转时长；菜单浮层共用 PopupMenuTransition 的淡入及展开效果。模型列表与思考强度内部切换同时使用公共页面淡入淡出和平滑高度过渡，系统减少动画时直接切换。聊天消息中的“来自智能体”作为来源元信息，与智能体 ID 统一使用 textColorTertiary，正文颜色保持原样。


## 对话中的智能体导航

创建、查询和打开智能体的工具结果包含 url，格式为 lilygobox://agent/<编码后的完整智能体ID>。模型可以使用 Markdown 链接引用真实智能体；不得猜测 ID 或拼造不存在的智能体。正文链接与“来自智能体”名称共用工作流内部导航，保留原对话草稿、滚动位置和返回历史，不重建会话，不自动执行目标智能体；智能体已删除或链接无效时显示本地化提示。应用内部协议不会交给系统浏览器打开。

open_agent 使用准确 agent_id 打开直接连接的智能体；名称重名时应先查询并确认。只有当前正在查看的对话发起调用时才切换页面，后台智能体返回智能体链接而不抢占前台。打开智能体不等于发送消息或启动执行。用时内仅保留普通导航操作记录，

断开普通沟通连接时，若智能体类型及所属关系都不改变，直接断开并支持撤销，不弹确认框。断开会改变主智能体／子智能体角色时，继续显示角色变化确认；批量操作只要包含角色变化，也需要确认，取消不得删除任何连接。

智能体 ID 采用“微秒时间戳-递增序号”，不添加前缀，内部存储、工具参数、复制内容与链接使用同一原始字符串。当前工作流数据格式为 version 2；不读取旧格式、不迁移旧测试画布，不提供历史类型或已移除工具的兼容别名。卡片模型行显示“模型服务：服务名称 · 模型名称”，卡片及对话右上角显示“智能体 ID：完整 ID”，使用本地化冒号格式。

框选拖动使用独立的 ValueNotifier 和 RepaintBoundary 更新覆盖层；鼠标移动不重建整个工作流、不重新测量所有卡片，也不重复计算布局和连线路由。按下与松开时才更新画布交互状态，松开后统一提交卡片及连线选中结果；4px 拖动阈值、Ctrl／Shift 累加与填充外观保持一致。

拖线预览也采用独立 RepaintBoundary 与可监听的 CustomPainter：指针更新只重绘预览线，不重建卡片、不重绘已有连线和背景网格。开始、结束或取消拖线才更新全局交互状态，继续使用原有 preview 曲线计算；预览层位于卡片下方、选框覆盖层下方，且不拦截鼠标。

正式连线不再读取第三方卡片矩形，也不进行重叠通道检测或分流。无论无关卡片被移动、增删或叠放，既有连线的曲线保持不变；只有两端卡片位置或尺寸变化才更新路径。绘制位于卡片下层，点击与框选共用绘制路径，被卡片盖住的区域优先响应卡片。

框选覆盖层不按原始场景矩形裁切，只由外层画布视口裁切。无限平移后，负坐标区域的选框边框与填充也必须完整绘制；验证需覆盖平移、缩放后的原始场景左侧和上方。

连线端口优先保持分支一致：两张卡片的水平方向存在间隔时，统一使用朝向彼此的左右端口和平滑贝塞尔曲线，不因上下分支高度差较大而切换至顶底端口。只有水平方向没有间隔时才按垂直排列选择顶底端口；不避让其他卡片，不生成直角走线，点击与框选继续使用同一条路径。此规则同时作用于已有连线和新增连线。

智能体卡片宽度保持 252，最小高度从 164 收紧到 144，减少短标题与模型服务之间的空白；文字缩放和长标题仍按内容测量增加高度，端口、选框及连线路由使用实际卡片尺寸。

侧栏“智能体工作流”是返回画布主页的入口：位于智能体对话页时仍可点击，点击后清空页面内对话跳转历史并回到画布；从设备或设置切入时也直接显示画布。只切换显示页面，保留智能体、聊天草稿、运行状态和画布位置，不停止正在执行的工作。

多分支连线不做通道偏移：同一端口发出的不同目标曲线（以及反向汇入的曲线）允许在端口附近自然靠拢，始终保留单条贝塞尔曲线，避免分支增多后出现多余的 S 形弯折。端点完全重合时曲线也允许重合，不因其他连线增删而改变既有路径。自动布局根据分支纵向跨度适当增加水平间距，小型树保持原有间距；手动布置的卡片位置不会为了美化连线被自动移动。

## 智能体通信动画

参考 Magpie `internal/gui/assets/plugins/routing/routing.css` 的独立流动图层：只有真实发生的 `spawn_agent` 初始分派和 `send_agent_message` 投递触发动画，不能按智能体 busy 状态推测通信，也不在接收方完成普通回复时伪造自动回信。子智能体实际发送回上级的消息沿同一连线反向传输；上级通过 `wait_agents` 或 `list_agents` 实际读取到子智能体的新回复时，也按子智能体到上级方向播放回传动画。同一接收方重复查询同一回复不重复播放，只在子智能体产生新的完整回复后再次触发。普通完成但尚未被读取时，不凭空播放回传。子智能体互发消息同样按真实发送者、接收者确定方向，不能假设连接存储的 from/to 就是本次发送方向。重复消息抑制、参数或目标校验失败不产生动画，无图示端点或没有直接连接也不绘制。

每次投递播放约 1.4 秒：原静态线暂时替换为主题紫色流动虚线，带柔和光晕的紫色圆点从发送端沿现有曲线移到接收端。两向同时投递可同时显示各自圆点，虚线以该线当前首个消息方向流动；结束恢复原有静态线及选中样式。点与线宽按缩放补偿。线条继续位于卡片下方，不拦截输入、不改变路由与连接关系。动画表达消息投递事件，不表示 API 网络进度或接收者工作完成进度。

通信事件通过独立 ValueListenable 发布，仅保留动画期间的发送方、接收方与时间，不存正文、不持久化。到期自动释放事件和定时器；整个工作流销毁时清理所有定时器。独立 RepaintBoundary / CustomPainter 在动画帧重绘虚线与圆点，不逐帧重建卡片、重算路由或重绘网格；静态图层只在通信开始或结束时切换线条。隐藏页面停用 ticker，空闲没有持续帧；减少动画设置下使用静态虚线与圆点提示，不持续运动。

创建智能体的执行模型选择复用聊天输入框 ModelSelector 的完整二级页面与过渡动画：当前模型支持思考强度时打开强度页，可返回模型列表，选择支持强度的新模型继续进入强度页；不支持时直接选择。模型和强度只写入创建窗口的独立会话草稿，取消不修改上级／全局配置；确认后在新智能体首个请求之前应用所选强度。选择继承上级时恢复上级的模型和强度。

画布触发 Ctrl／Meta+A、C、V、Z、Y，以及 Delete、Backspace、Escape、空格交互时关闭现有右键菜单；Ctrl+滚轮缩放和滚轮平移也先关闭菜单。鼠标位于右键菜单上时 Ctrl+滚轮由菜单转交画布缩放并关闭菜单，普通滚轮仍保留菜单本身滚动，不穿透画布。聊天页和文本输入框保持自己的快捷键处理。
