# 主页智能体工作流

## 入口与拓扑

首次打开非空画布时，先恢复数据并测量卡片，再按实际视口确定初始缩放和中心。没有保存画布坐标时，世界坐标 `0,0` 是默认中心，主智能体卡片中心落在 `0,0`，下级按自动布局从该锚点展开；保存过的位置始终优先恢复。第一帧画布使用这个视角构建可见卡片，不先显示默认视角再跳转；只有达到最小缩放仍看不到任何卡片时，才以一张卡片为中心。正常平移、切回页面不重新居中。

### 通用计时

计时由应用时钟负责，不以模型输出长度、轮数或思考强度估算时间。主、子智能体都可在实际开始限时活动时调用 `start_timer`（1–86400 秒、任务目标）。每个智能体最多有一个运行中的计时，重复启动不会重置截止时间；新的计时替换自己的上一次已结束计时。`get_timer` 查询、`wait_timer` 等待、`cancel_timer` 取消都只作用于自己的计时，知道他人的编号也不能操作。

到期只改变计时状态，不插入聊天消息、不新开模型回合，也不中断其他工作。只有 `expired` 表示达到截止时间；需要到点行动时，智能体应在当前回合结束前主动调用 `wait_timer`。子智能体按任务要求通过正常通信向分派者回报结果；主智能体可独立设置汇总时限、到点汇报已有结果并标注未完成事项。任务允许提前结束时可取消自己的计时。无人等待时不会自动汇报。

切换页面、断开连接、变更角色或移交管理权不改变个人计时。手动和智能体引导都不会打断已开始的工具等待或改变个人计时。停止单个智能体只取消它自己的计时，停止全部才会取消所有计时。个人计时保存在 `ai.personalTimers.v1`，不随智能体包导入、导出或复制；不读取或恢复旧版共享计时。重启后重新核对个人计时截止时间，不恢复旧等待回合。已有聊天记录保留，不再生成计时通知。

工具统一描述可复用能力，而不是固定业务场景。计时、通信、记忆、文件、网页、命令和设置等能力由用户目标组合使用，不要求固定的讨论、开发或研究流程。能力本身的范围、运行限制及授权检查仍然保留，不因通用化而扩大权限。

随模型请求发送的工具说明只保留用途、必要的调用方式与边界。参数已定义的取值范围不在说明里重复；界面细节和内部执行流程不放入每轮请求。工具说明不替代实际的权限与审批检查，启用角色卡也不会改变工具访问范围。

### 主子智能体的管理权限

**经验：管理范围取决于当前归属树，不取决于有没有画通信线。** 例如 `A → B → C → D`，主智能体 A 可以直接给 C 或 D 分派、查结果、立即引导、停止、删除或调整模型，不需要用户补线，也不需要 B 转达；子智能体 B 可以管理 C，但不能跳过 C 管理 D，即使 B 与 D 有通信线。普通消息默认排队；只有纠正方向或变更任务时才使用立即引导，不能借此恢复被用户手动停止的智能体。

| 操作者 | 管理范围 | 仍然不能做的操作 |
| --- | --- | --- |
| 主智能体 | 本工作流任意层级的下级：创建时指定组内上级、调整分支、引导、停止、删除、配置模型／思考强度／速度；可批量操作明确指定的下级、维护组内补充通信线、整理本组布局 | 跨工作流管理、通过通信线取得管理权、自行换主或拆分为独立工作流 |
| 子智能体 | 创建、引导、停止、删除和配置自己的直属下级；与直接相连的智能体正常通信 | 干预上级、同级、非直属后代或其他分支；批量管理、改组内拓扑或布局 |
| 用户 | 手动换主、合并或拆分工作流；按需调整归属和连线 | 画布操作不授予智能体文件、命令或系统权限 |

实现新工具时，应在执行时根据当前归属校验每个目标，不能只靠工具提示或缓存的旧拓扑；批量操作应先校验整批权限，再修改数据。排查“仍要人工补线或转达”时，先核对智能体是否用了正确的工具，再判断是否缺少权限，不为单次模型误判扩大管理范围。

主智能体可以用 `spawn_agent` 的 `parent_agent_id` 直接创建本树任意有效成员的直属下级，例如先创建 B，再把 C 创建到 B 下；新智能体继承调用者的配置和权限，任务来源仍是实际调用者。子智能体不传该参数，只能创建自己的直属下级。`reparent_agent` 可将组内下级及其分支移到本树有效成员之下，沿用手动换上级的循环检查，不允许跨组、拆组或提升为独立主智能体。

主智能体可用 `stop_agents`、`delete_agents`、`configure_agents` 批量处理本树指定下级。批次中有组外、自身或无效目标时整批拒绝；删除只回收选中目标，保留分支接回最近仍存在的上级；批量配置使用相同参数，逐项返回结果，忙碌或不兼容的目标不修改。`layout_workflow` 在画布已挂载、无拖动或撤销操作时复用自动布局，只重排本树，保留其他工作流卡片位置及当前视角。子智能体仍无这些批量和布局权限，不扩大文件、命令或其他系统权限。

`spawn_agent`、`configure_agent` 和 `configure_agents` 支持用户明确指定 `processing_speed`（`standard` / `fast` / `ultrafast`）。主智能体可以创建并配置本树内的下级，子智能体只能创建并配置自己的直属下级。模型按服务 ID 与模型 ID 一起指定，思考强度和速度仅接受 `list_agent_models` 中该服务和模型支持的档位。不显式指定速度时，创建沿用继承或所选模型的已保存设置；修改时不选模型就保留当前速度，选模型则使用该模型的已保存设置。不支持的档位不会替换成其他档位；修改失败的目标保留原配置，忙碌目标不停止也不排队改动。处理速度是服务档位，不是固定倍速，实际表现和计费由服务商决定。

当前角色结构要求主智能体无上级、子智能体有上级。创建、启动恢复和导入时拒绝无上级的旧子智能体数据，不自动补上级、变更身份或恢复旧孤立角色。

卡片双击采用 500 毫秒点击间隔，同次点击移动不超过 8 个逻辑像素；超过移动阈值才开始拖动，避免鼠标微动取消双击。真正拖动、组合键多选、空格平移和取消指针均不作为双击打开对话。

### 拓扑查询与手动更换主智能体

应用是唯一拓扑数据源：管理树使用单一上级 ID，通信图使用邻接集合，两者与画布坐标分离。只在关系变化时重建查询索引；模型通过 `get_agent_topology` 获取自身任务组、管理边、通信边及版本号，不向每个模型反复塞入完整画布。相邻的外部任务组仅作为通信邻居出现，不授予管理权限。

只有用户能在画布上更换主智能体：右键本组未关闭的子智能体，选择“设为本工作流的主智能体”。应用只反转它到原主之间的管理路径，例如 `A → B → C` 变为 `C → B → A`。其他分支、补充通信连线和卡片位置不变，整组仍只有一个主智能体。此操作不弹确认框，支持画布撤销和重做；更新后的关系照常保存及导入导出。会话、模型、记忆、个人计时和正在执行的任务不迁移、不停止，也不会自动启动新主或发送交接消息。智能体可查询最新关系，但没有更换或撤销更换主智能体的工具。

主智能体可按用户要求用 `connect_agents` / `disconnect_agents` 连接或断开同组补充通信边；不能跨组管理，不能通过断开工具删除管理边，断开不删除卡片、不停止任务。重复断开返回已断开状态，之后仍可重新连接。

自动检索长期记忆在同一用户轮次的工具续轮中复用；新轮次或记忆写入、删除、导入等内容变化后重新检索。显式记忆搜索始终实际执行。回答记录独立完成时间并随会话存储、复制和导入导出；助手消息仅显示完成时间，尚未完成时不以开始时间替代。会话消息必须包含当前格式的时间字段及步骤、重试、附件和事件列表，时间值可显式为 null；缺少字段的旧记录拒绝读取，不补齐迁移。

手动停止优先取消当前网络、等待和可取消工具，后续智能体来信保留在队列，不自动重启已暂停智能体；用户发送、继续或手动引导可恢复。停止不能撤销已提交的外部副作用，也不强行中断同步代码。

画布顶部不再使用整行标题栏：左上角独立显示点阵图标和“智能体工作流”标题，使用与底部说明栏相同的主题背景色，外形为 8px 小圆角长方形，内部左右留白 12px、上下 10px；操作使用顶部居中的悬浮胶囊工具条，以画布视口而非整个应用窗口为中心。工具条复用公共 MenuItemSurface、主题表面色和卡片阴影，创建主智能体、添加子智能体和删除始终显示；没有适用选择时置灰禁用。选中智能体后启用删除，不因选中变化增减按钮。悬停使用与右键菜单一致的主题紫色和 onPrimary 文字／图标，选中及点击反馈由同一公共菜单组件管理，禁用项没有悬停或点击反馈。布局尺寸变化采用 180ms 过渡，减少动画模式直接切换。根据当前语言、文字缩放和操作内容测量所需宽度；空间不足时将工具条放到标题下方居中，按钮必要时换行，保持至少 16px 左右边距。工具条不随画布平移、缩放，底部视图工具栏维持原有布局。

主页直接显示智能体拓扑，不新增全局侧栏页面。空白工作流提供“创建主智能体”入口；顶部工具按钮常驻，只有选中适用智能体时启用对应操作。主智能体由用户明确创建或指定，可有多个独立的主智能体组，也可没有下级。所有身份均显示为卡片，分别持有独立对话，卡片显示名称、执行模型、智能体类型、智能体 ID 和当前状态。智能体 ID 使用会话注册表原始标识，卡片和智能体详情顶部均显示完整值，不截取尾部、不以省略号截断；宽度不足时自然换行，并计入卡片自适应高度，右键复制始终复制完整 ID。智能体类型与状态图标使用 fill 样式。两种身份的类型标题在卡片和详情顶部统一使用 12px、w600，类型图标统一为 18px，卡片高度测量同步采用该规格。画布支持平移、缩放、拖动节点与重置视图。底部工具栏可选择点阵、网格或纯色背景，默认点阵；背景按钮左键按点阵、网格、纯色循环切换，右键打开公共选择菜单，按钮及菜单为三种样式使用不同图标。偏好独立保存于 ai.agentCanvasStyle.v1，不包含智能体授权。节点手势提供的局部拖动距离不重复除以画布缩放比例，保证缩小或放大后仍跟随鼠标。工具条及画布菜单的放大、缩小，以及手动重置视图，使用 200ms、Curves.easeInOut 的位置与缩放插值过渡，手动操作可打断；减少动画模式和首次自动布局直接定位。节点右键菜单复用公共 RightClickMenuBuilder 模板，提供打开对话、添加下级、复制智能体 ID、停止执行和删除智能体；打开对话、复制 ID 和添加下级作用于右键智能体，停止、断开和删除作用于当前选择组。

只保留主智能体（primary）和子智能体（沿用存储值 permanent）。一组相互连通的卡片是一条工作流，每条工作流只能有一个主智能体；不同且不相连的工作流可各自拥有主智能体。默认独立创建主智能体，带上级创建或模型分派时创建子智能体。两种身份都持有独立对话，都可继续分派，不固定层数。右键“拆为独立工作流”将当前管理子树拆成独立工作流，清除其与原组的边界连接、保留内部连接；“更换直属上级”移动委派分支并成为子智能体，同时清除跨越新管理组边界的额外连接。不弹角色变化确认框，支持撤销和重做。

删除只移除明确选中的智能体，不递归删除下级。删除中间子智能体时，保留的直属下级自动接给原上级；批量删除连续多级时，沿原管理链找到最近未删除的上级，并自动建立归属连接，不依据额外沟通连线猜测上级。删除主智能体时，由最后创建的未选中直属子智能体接任，其余失去原上级的分支连接到它下面；没有可接任直属下级时沿用独立分支规则。保留节点的 ID、对话、模型、权限与运行状态，不重置自动消息额度。已删除节点进入回收站，恢复时有有效上级则为子智能体，否则为主智能体；回收站恢复不抢回已重新归属的活动下级，完整恢复删除前结构使用画布撤销。

用户在画布通过工具栏、右键菜单或 Delete 键删除单个或多个智能体时直接执行，不弹删除确认框或附带的身份变化说明；与 AI 删除共用同一底层计划，支持画布撤销／重做，归属和连接一并恢复，已删除数据进入回收站。主智能体可以通过 stop_agent、delete_agent 管理整棵管理树内的后代，不要求直接连线；子智能体只能管理自己的直属下级。不能管理自身、上级、同级或仅通过通信连线相连的其他组智能体。停止仅作用于指定目标；删除仅停止目标的生成、取消批准和提问、终止并清理其进程，未删除分支继续运行并按上述规则重新归属。若用户撤销历史仍引用被删除智能体，已停止的会话只为恢复保留，历史引用释放后销毁。已完成智能体不会仅因完成状态就自动销毁或从工作流消失，需由用户或具有管理权限的智能体明确删除。

拓扑保留单上级的任务委派树，供生命周期管理和自动布局使用，并允许组内额外建立双向通信连接，沟通关系允许多对多和环。连接不同工作流的任意主／子卡片都会合并管理树，不能保留跨树通信造成一条工作流存在多个主智能体。主智能体可查看、等待、发送消息、引导和打开本管理树内任意后代，不要求额外连线；子智能体的通信与查询仍限直接相连范围。主智能体可停止、删除和配置全部管理后代，子智能体仅可引导、停止、删除和配置直属下级。AI 无权连接或管理其他工作流；用户手动合并后，按新的归属计算管理范围，不增加文件或系统权限。委派关系禁止循环和多上级。断开边后若仍有其他路径相连，沿剩余连接调整归属，保持原组主智能体；只有真正分离出的连通分量才产生独立主智能体，不增加额外连线。连线根据两端位置绘制平滑贝塞尔曲线，不添加方向箭头或避障分流。

身份、上级、组长或直接通信对象变化后，将最新 agent_relationship_update 系统事件加入该智能体的下一次模型请求，不主动启动生成，不在界面弹提示。事件包含 agent_id、role（primary / child）、parent_id、primary_agent_id、connected_agent_ids 和 managed_agent_ids。关系不变时不追加事件；压缩移除旧事件后会补回当前关系。关系快照随会话持久化，导入和复制后按新 ID 重算。该事件只说明关系，不授予用户权限。

数据格式仍为 version 1，只接受和写入 primary / permanent。部分导出省略上级时将节点作为主智能体导出；导入重新分配 ID、重置权限，不包含模型密钥。复制粘贴、回收站及撤销重做只处理主／子两种身份，保留可用通信关系。

画布可以持续向各方向平移，渲染场景按卡片位置动态扩展；卡片向左上跨过场景原点时统一重置内部坐标并反向补偿视图，保持鼠标下的位置连续，不限制拖动方向。视口边缘正常裁剪画布，卡片不会溢出盖住侧栏。底部说明与视图工具使用独立工具栏，不能悬浮遮挡可操作的卡片。视图缩放存在下限，智能体很多时不能保证全部同时出现在窗口内，仍需平移浏览。智能体总数与子智能体同时运行数量不设固定上限，实际承载能力取决于本机资源和模型服务；创建、复制、消息投递及输入框发送不因其他智能体正在运行而拒绝。

“自动布局”清除当前页面的手动卡片位置，按智能体树重新排列并以 200ms 动画调整视角；“重置视图”只调整位置与缩放，不改变卡片排列。两者在底部工具栏中提供独立入口，减少动画模式下直接定位。工具栏保留主题长条背景，内部统一使用 24px 纯图标按钮（内部图标保持 17px）和 4px 方形圆角；外层与右键菜单一致，圆角为 8px、内边距为 5px，按钮之间间距为 4px；功能名称只在悬停提示和无障碍标签中显示。按钮复用公共 MenuItemSurface，与右键菜单使用相同的主题紫色悬停反馈和选中配色，不使用圆形按钮背景。

## 卡片与画布编辑

聊天左上角的名称按钮与“智能体工作流”标题共用 10px 圆角、左右 12px 和上下 8px 留白。名称按钮默认无底色，悬停只渐变主题悬停色的不透明度，按下使用点击反馈，不改变区域大小；整个区域都可点击重命名。两行高度限制只作用于内部名称滚动区，不包含按钮留白。

卡片选中边框沿用聊天输入框：1px 主题紫色与透明色之间以 180ms、Curves.easeOut 过渡，减少动画模式直接切换；边框绘制在前景，不改变内容尺寸和布局。卡片宽度固定为 252px，最小高度 164px，名称按完整内容自然换行并自动增加卡片高度，不截断、不使用内部滚动条；文字缩放时同步适配。卡片高度按实际文字样式、缩放、方向和语言测量，连线、连接点、框选、命中区域、场景边界与自动布局统一使用各卡片的实际尺寸。重命名保持卡片左上角和当前视角，自动布局按新高度重新排列。单击选中、双击打开、节点数量变化及窗口/工具区尺寸变化均不触发自动居中；只在初次呈现画布或空画布首次加入智能体时自动定位，其后由“重置视图”或“自动布局”主动调整。智能体对话顶部名称仍最多显示约两行高度，超出后独立纵向滚动，保留完整名称；只绘制一份滚动条，距名称区域右边缘及上下两端 6px，文字右侧预留 20px。返回按钮保持稳定，不被长名称撑开；智能体类型、服务与模型、完整智能体 ID 放在顶部右侧并右对齐，使用无背景、无边框的文字布局，智能体类型左侧使用对应 fill 图标。名称放在左侧可用区域，长名称换行并保持限高滚动，滚动条不常驻。卡片智能体 ID 上方显示“服务分组名 · 模型名”，分组沿用选择模型菜单的 service.name；找不到服务时仅显示模型名，单行溢出省略并提供完整悬停提示。

卡片主体仅使用公共 CardShadow 阴影，不使用 TiltCard 倾斜或重力效果，默认无描边，不添加按压填色或点击波纹。仅选中时显示主题紫色边框；卡片主体、连接点和选中边框均保持稳定坐标。工作中的智能体在右上角显示状态灯，等待批准或回答使用对应提示状态。

单击选中，点击另一张卡片替换选中，Ctrl / Shift 点击增减选择；空白处点击清空选择，由框选同一条指针松开路径提交，不依赖框选覆盖层重建期间的 Tap 识别。空白处右键同样清空卡片选中并关闭卡片菜单，弹出公共画布菜单，提供缩小、放大、自动布局、三种背景选择及重置视图；右键连线仍提供断开操作，断开前弹窗确认，按剩余连接自动调整主智能体与子智能体，保留名称、ID、模型、权限及历史；右键拖动只平移、不弹菜单；普通左键拖动空白处框选，Ctrl / Shift 拖动保留原选区；框选使用主题紫色外框与 8% 透明填充，作为不接收指针事件的最上层覆盖在所有卡片之上，拖动期间屏蔽卡片与创建入口的悬停、点击和拖动，松手后才提交选区；右键拖动超过手势阈值后平移，右键单击仍打开原有菜单，拖动松手不弹菜单。Ctrl 加滚轮以鼠标位置为中心平滑缩放，使用 200ms、Curves.easeOut 过渡，首次操作不要求预先聚焦画布；连续同向滚轮累计目标比例并从当前画面重新衔接，反向时从当前比例响应，避免动画重启丢失缩放量。鼠标拖动、其他视图操作可打断，减少动画模式直接定位；普通滚轮上下平移画布，Shift 加滚轮左右平移，Ctrl 优先用于缩放；滚轮平移同样使用 200ms、Curves.easeOut 动画，连续同向滚动累加目标位移，反向从当前画面响应，减少动画模式直接定位。Space 加左键和鼠标中键保留为辅助平移方式，画布快捷键不能接管输入框的空格。滚轮处理限定在画布内部，不接管聊天或弹出菜单的滚动。选中的卡片可共同拖动，右键已选卡片保留整组选中，右键未选卡片改为选中该卡片。批量菜单复用公共右键模板。画布获得焦点时支持全选、Delete、Ctrl/Cmd+C 和 Ctrl/Cmd+V，不能劫持搜索、智能体名称、聊天等输入框的编辑快捷键。复制保存所选卡片的名称、完整工作内容、服务与模型、思考强度及权限快照；粘贴按会话分支创建新 ID 的独立副本，继承复制时的聊天、图片附件、操作展示记录与模型上下文，不复制未选中的下级。多选一起复制时保留选中节点之间的归属连接与额外沟通连接，不把副本自动接回未选中的沟通对象。系统剪贴板仅写入应用内识别标记，内容快照保留在当前工作流页面内存，不包含密钥；剪贴板被其他内容覆盖后不粘贴旧卡片。每次粘贴相对复制位置递增偏移 40px。

手动画布连线（拖动连接点或“连接所选智能体”）共用状态层连接入口。连接不同工作流时保留起点所属主智能体，将终点设为起点的直属下级；终点原有上级路径反向接到终点下方，使原主智能体也成为子智能体，路径之外的分支保持原归属。因此无论主连主、子连主、主连子还是子连子，都合并完整工作流，保留全部卡片、对话、模型、权限和已有连线，不凭空新增其他连线。同树连接只增加沟通边，不改变管理关系；反向重复连接不会改选主智能体。不弹合并或角色变化确认，整个调整为一个可撤销步骤。恢复、导入、复制粘贴、撤销／重做均校验单主规则；已有数据出现多主连通分量时保留记录顺序中最早的主智能体，沿现有连接合并其余管理树，不删除卡片或对话。导出局部数据也按所含连接计算唯一主智能体，不改动原工作流。AI 的 `connect_agents` 仅允许本组内部连线，不能借此跨组合并。重复连接不产生重复边，不允许自连或已关闭智能体参与。恰好选中两张尚未直接连接的卡片时，右键显示“连接所选智能体”，以右键卡片为起点；已直接连接时隐藏该项。卡片菜单的“断开连接”断开所选智能体关联的全部连线，保留对话与智能体。

子智能体的右键菜单区分“设为本工作流的主智能体”和“拆为独立工作流”，前者保留整组，后者保留当前子树及其内部连线，但断开与原组的连接。右键“更换直属上级”通过公共弹窗选择合法上级。角色切换以当前右键卡片为目标，不批量套用到选择组。右键“重命名”使用公共标准弹窗，名称限 1–200 个字符，去除首尾空白，取消不改变智能体；名称同步更新卡片和对话标题，不修改 ID 或其他智能体信息。上级候选排除自身、所有后代、已关闭智能体；没有合法候选时隐藏入口。右键“置于顶层”只调整当前卡片在页面中的叠放顺序，不改变连接、模型或智能体关系；选框覆盖层始终高于所有卡片。显示层级仅在当前页面保留。右键“复制卡片”复制当前智能体完整名称、工作内容、模型、思考强度和权限；名称使用递增数字后缀，如“名称 (2)”“名称 (3)”，复制已有编号的智能体时继续递增且跳过已用名称，不叠加后缀；数字后缀超过 200 字限制时保留完整原名，不截字；新建独立 ID，沿用原智能体类型及上级，继承复制时的对话历史、图片附件、操作展示记录和完整模型上下文，两边后续对话互不影响；不复制下级、活动进程、待批准或待回答状态，不自动执行。未完成工具调用在副本上下文中记录为取消，不重放操作。已有对话的副本输入框留空；尚未开始的智能体保留原智能体草稿。副本放在原位置右下 40px，创建后选中而不自动打开对话。

角色改变保留原智能体 ID、对话、模型、权限与手动位置；提升为独立主智能体时清除子树边界上的外部连接，内部沟通连接保留；沿用归属树的循环校验。设置上级使用选择窗口，不追加角色变化确认；删除引起的身份调整与删除操作同步执行，不单独提示，撤销删除时一并恢复关系。

拆分或合并智能体树时保守保留自动通信额度和去重记录，不能通过断开、重新连接重置额度。同树内移动不重复累计。批量删除先确定明确选中的子智能体分支，再处理主智能体接任，避免把已明确要求删除的智能体重新提升保留；祖孙重复选择只释放一次。

交互参考：[React Flow 基础交互](https://reactflow.dev/learn/concepts/adding-interactivity)、[连线重接](https://reactflow.dev/examples/edges/reconnect-edge)、[连接验证](https://reactflow.dev/examples/interaction/validation)、[Blender 节点编辑](https://docs.blender.org/manual/en/latest/interface/controls/nodes/editing.html)。本项目以单上级归属树管理智能体生命周期，额外的无向沟通连接只提供直接相邻智能体的通信能力，不将连线解释为文件权限授予。

## 会话与协作

双击节点或使用“打开对话”在主页内部打开完整会话，返回工作流仍保留页面状态。返回入口沿用设备页面的圆形 TitleBarIconButton：28px 按钮、18px 箭头，旁边显示智能体标题，只有按钮本身触发返回。会话复用主聊天的流式回复、用时详情、文件/网页/命令工具、批准卡片与提问卡片；稳定智能体 ID 和公共保留页面容器用于保存草稿、滚动位置与焦点隔离，页面采用公共淡入动画。所有主智能体和子智能体均提供普通输入框，可由用户继续对话。

| 工具 | 用途 |
| --- | --- |
| `list_agent_models` | 查询服务和模型 ID，以及各服务模型支持的 `reasoning_efforts` 和 `processing_speeds`；不返回密钥或端点 |
| `spawn_agent` | 创建并启动可见下级，可指定服务、模型、思考强度与速度，返回实际配置 |
| `configure_agent` / `configure_agents` | 修改空闲下级的模型、思考强度或速度；主智能体可改管理树内任意下级并批量配置指定目标，子智能体仅可单独修改直属下级 |
| `list_agents` | 查询相连智能体的状态和可用结果 |
| `send_agent_message` | 默认排队投递；主智能体可立即引导本树后代，子智能体仅可立即引导直属下级 |
| `wait_agents` | 有界等待，返回当前状态和结果；等待对象发来的普通消息可结束等待并交回当前轮 |
| `stop_agent` | 主智能体可停止全部管理后代，子智能体仅可停止直属下级；保留卡片、对话及未指定后代的运行 |
| `delete_agent` | 主智能体可删除全部管理后代中的指定目标，子智能体仅可删除直属下级；保留分支并自动接给原上级 |

各智能体独立持有聊天历史、请求取消信号、HTTP 响应订阅、进程会话、批准与提问状态。创建子智能体默认只传工作内容，不复制主智能体完整历史；分派内容应包含目标和必要上下文。消息记录标明来源智能体，不把智能体之间的消息伪装成用户输入。消息投递不能绕过待批准、待回答状态。同一主智能体下整棵智能体树共享 12 次自动消息额度，相同来源、目标与正文的重复投递被抑制，实际人工输入后重置额度。接收消息后是否回信由模型决定，执行层不生成自动回信。

主智能体和子智能体均可独立运行，不设固定并发名额；后续请求沿用该智能体上下文。查询结果返回最近一段非空回复，超过 16,000 字符时截断并标记。等待工具有时间上限，停止等待不等于停止子智能体。执行结果不会直接插入另一会话正文，需要通过消息或查询取得。

## 模型与权限

`configure_agent` 接受 `agent_id`，以及可选的 `service_id`＋`model` 和 `reasoning_effort`，至少提供一种修改。目标可从 `get_agent_topology` 查询，不要求主智能体与间接下级有额外沟通连线；沟通连线本身不授予管理权限。禁止修改自身、上级、同级和其他组的智能体。目标忙碌（包括等待工具、批准或回答）或正在保存配置时返回 `configured: false`、`reason: busy`，不排队、不停止或重启目标。模型、密钥可用性、思考挡位及已有／待发送图片兼容性在修改前统一校验，失败不部分应用。未指定模型时保留当前模型；更换模型但未指定强度时使用目标模型已保存的强度。成功返回实际模型与思考强度，仅供后续请求使用，保留聊天和权限，不修改全局配置。调用沿用工具操作记录展示，不增加权限确认框。

用户创建主智能体或子智能体时可选择已配置的服务和模型；新智能体默认继承直接上级的选择，主智能体默认沿用当前服务。子智能体可使用其他已配置服务的模型；未指定时继承所属智能体的模型配置。每个智能体持有独立模型配置，调整其模型不覆盖其他智能体。端点与密钥成对保存在会话内存快照，避免服务编辑后旧端点收到新密钥；密钥不进入智能体工具参数或智能体持久记录。删除共享服务不等于撤销已运行会话中的旧内存快照，需要停止对应智能体或明确重新选择模型。

对话分派时先通过 `list_agent_models` 查询真实配置，再向 `spawn_agent` 同时传入准确的 `service_id` 与 `model`。两个参数必须同时指定或同时省略；只指定一个、服务不可用或模型不属于该服务时拒绝创建，不使用相似名称匹配或默认模型兜底。名称存在歧义时，工具说明要求通过现有 `request_user_input` 提问确认；语义理解由模型完成，执行层负责校验准确 ID。服务列表不暴露密钥或地址；创建与查询结果返回 `service_id`、`service_name` 和实际 `model`。目标服务和模型在首次请求前设置，独立使用该服务的协议、端点、凭据及已保存的模型强度配置。此流程只选择已有服务，不创建服务、不修改全局模型，也不提升继承的权限。

`spawn_agent` 可单独指定 `reasoning_effort`，从 `list_agent_models` 返回的目标模型 `reasoning_efforts` 中选择准确值；空列表表示不支持可配置的思考强度。仅在目标模型列出 `none` 时可用它关闭思考。不接受未知、无效类型或目标模型不支持的挡位，不自动替换为其他挡位，校验失败不创建智能体。不传该参数时，继承模型则继承上级强度，显式选模型则沿用该模型已保存的强度配置；覆盖只作用于新智能体，在首次请求前生效，不修改上级或全局配置。创建与查询结果通过 `reasoning_effort` 返回实际强度。

例如：“创建子智能体，用某服务的 DeepSeek 检查代码，之后我单独沟通”，或“派 GPT 模型核对结果，完成后汇报”。无论工作时长或用途，均创建可见、可手动管理的子智能体，采用相同的模型选择和权限规则。

智能体创建、重命名及选择上级弹窗的表单字段统一采用编辑服务样式：主标签使用 `AppDialogStyle.fieldTitleStyle`，下方 4px 显示 `descriptionStyle` 简短说明，再留 8px 放置控件。智能体名称、执行模型、权限、工作内容及上级选择都需提供对应说明，不以窗口顶部介绍替代字段说明。

创建时智能体名称可选；留空则由该智能体所选服务与模型独立生成简短名称，不提供执行工具，不写入智能体对话或历史。创建不等待命名请求：先从工作内容截取简短摘要，立即显示卡片并开始执行，后台命名成功后更新名称。命名请求最多等待 20 秒，失败、超时或无效输出时保留摘要；用户在等待期间手动改名后不覆盖，删除智能体时取消命名请求。用户明确填写的名称不额外请求、不被覆盖；重命名仍要求非空。模型工具 `spawn_agent` 的 title 同样可省略，工作内容必填。

创建窗口的执行模型菜单复用聊天区的选择模型组件，使用相同的搜索、服务分组、选中样式和滚动规则；只有创建子智能体时保留“继承上级模型”选项；主智能体没有上级，直接显示当前选中的实际服务与模型，并可自行切换。可识别的 OpenAI 和 DeepSeek 模型显示品牌图标，其他模型使用默认点阵图标。模型选择下方复用聊天区的权限菜单及审批配置页。创建弹窗内，模型、权限、角色卡模板和开场白按钮使用相同的下拉控件背景、4px 圆角、30px 常规高度、12px 文字、16px 前导图标区域及 14px 箭头。模型、权限和角色卡模板下拉浮层在空间足够时从按钮下方 8px 左对齐展开，收起时箭头向右，展开时向下；开场白仍打开预览选择弹窗。此窗口模式不改变主聊天的按钮与菜单定位。创建前的配置只存于窗口内的独立草稿，取消不改变上级或全局配置，确认后在首轮执行前应用于新智能体。

新智能体默认继承创建时上级权限，用户可在创建窗口明确调整；模型分派仍只能继承上级权限，不能通过创建参数提升权限。文件、命令、网页调用继续由执行层检查，危险命令与 forbidden 规则沿用公共实现。批准和提问属于发起操作的会话，不能由另一个智能体代替用户批准。并发智能体不具备文件冲突隔离；内置写文件保留 expected_content 校验，命令行修改仍需合理划分智能体范围。本功能不创建 Git 工作树或操作系统沙箱。

## 本地保存与恢复

智能体记录使用独立 SQLite 数据库，完整保存聊天、附件、用时、模型上下文、摘要、归属关系、额外连接及画布位置，不再将生产会话写入普通偏好中的旧文本快照。具体格式和限制见[智能体记忆与存储](agent-memory-storage.md)。

恢复按父子依赖建立智能体树，不依赖记录排列顺序；损坏、环状或缺少上级的记录不能静默覆盖原保存。恢复只重建数据，不重放工具调用，不恢复活动进程、待批准或待回答对象，不自动执行。权限恢复为默认值。服务被删除、模型不存在或密钥不可用时，保留节点与历史并禁用发送，需重新选择有效模型。

智能体数据包与模型服务配置分开导入导出，不包含服务 API 密钥。导入按新 ID 创建副本，记忆冲突先审查，数据库事务失败回滚。

框选同时支持卡片和连线，按连线路径与选框相交判断，松开鼠标才提交选中。Ctrl / Shift 框选累加原选区，连线使用主题紫色高亮；Delete 或连线右键菜单可一次断开选中的多条连线，保留聊天，不弹连线或角色变化提示。

普通右键菜单以鼠标位置处理上下／左右边界，溢出时相对鼠标翻转，不相对整张卡片翻转，四周至少保留 8px。画布开始新一轮点击或拖动时关闭已有菜单，右键拖动松手不重开菜单。连线单击、Ctrl / Shift 增减选中、空白处取消与卡片一致；左键按下时不显示选框，拖动超过 4 个屏幕像素后才显示并进入框选，轻微抖动仍按单击处理，不随画布缩放放大抖动。已打开菜单区域的右键拖动同样关闭菜单并转交画布平移，不能残留浮层或在松手时重开。

混合选中卡片与连线后删除时，先按原归属执行节点删除／接任和下级接续，再移除其余明确选中的连线，避免提前断线改变删除范围。整个操作直接执行并作为同一步骤撤销。Ctrl/Cmd+A 选中画布上的全部卡片与连线，包括视口外的部分。

自动布局同时考虑归属与沟通连接，将连通分量分层、同层分支错开，按实际卡片尺寸留出间距。额外沟通连接参与分层，使孤立沟通链也能分散排列。连线由两端卡片决定，绘制、单击命中和框选都以同一条曲线为准，屏幕绘制可按缩放精度批量处理。手动移动保持原位置，自动布局由用户明确触发。[大画布的绘制规则](flutter-upgrade-performance.md#上千张卡片的首次加载与平移)

智能体详情右上角只展示智能体类型及完整智能体 ID，模型服务与模型名称在下方输入区展示，避免重复。设为主智能体的菜单图标与主智能体卡片统一使用 fill 的 hub 图标。

## 工作流撤销与重做

画布获得主焦点时，Ctrl/Cmd+Z 撤销一步，Ctrl/Cmd+Y 或 Ctrl/Cmd+Shift+Z 重做一步。智能体移动以一次完整拖动为一步；自动布局、置于顶层、创建、复制／粘贴、重命名、连接／断开、角色调整和删除均作为独立步骤。确认框取消或未发生修改时不记录；撤销后进行新编辑会清空重做分支。保留最近 30 步，离开该页面生命周期后释放历史。

撤销恢复原智能体 ID、连接、角色及卡片位置，删除智能体的聊天上下文保留以支持恢复。撤销或重做拖动只改本次移动的卡片位置，保留后来新增的卡片。恢复不会重放命令、重新发送消息或重启已停止操作，也不回退聊天正文、权限批准及自动通信额度。输入框和对话内的撤销／重做由文本编辑器处理。平移、缩放和单纯选择不单独计入编辑步骤。

拖线预览根据鼠标相对起点的主方向选择水平或垂直控制点，并按正负方向调整弯曲；控制点位于两端之间，反向拖动不能出现越过端点的回钩。该预览只绘制待建立连接，实际连接规则及已有连线路由不受影响。

执行模型与权限作为表单字段时，展开箭头统一使用 expand_more，关闭时向右、展开时向下，沿用相同的线性旋转时长；菜单浮层共用 PopupMenuTransition 的淡入及展开效果。模型列表与思考强度内部切换同时使用公共页面淡入淡出和平滑高度过渡，系统减少动画时直接切换。聊天消息中的“来自智能体”作为来源元信息，与智能体 ID 统一使用 textColorTertiary，正文颜色保持原样。


## 对话中的智能体导航

创建、查询和打开智能体的工具结果包含 url，格式为 lilygobox://agent/<编码后的完整智能体ID>。模型可以使用 Markdown 链接引用真实智能体；不得猜测 ID 或拼造不存在的智能体。正文链接与“来自智能体”名称共用工作流内部导航，保留原对话草稿、滚动位置和返回历史，不重建会话，不自动执行目标智能体；智能体已删除或链接无效时显示本地化提示。应用内部协议不会交给系统浏览器打开。

open_agent 使用准确 agent_id 打开直接连接的智能体，主智能体也可打开没有直接连线的管理后代；名称重名时应先查询并确认。只有当前正在查看的对话发起调用时才切换页面，后台智能体返回智能体链接而不抢占前台。打开智能体不等于发送消息或启动执行。用时内仅保留普通导航操作记录。

连接、断开、切换角色和删除直接生效，画布操作支持撤销，不弹连线、角色变化或删除确认框。

智能体 ID 采用“微秒时间戳-递增序号”，不添加前缀，内部存储、工具参数、复制内容与链接使用同一原始字符串。当前工作流数据格式从 version 1 开始；不读取旧格式、不迁移旧测试画布，不提供历史类型或已移除工具的兼容别名。卡片模型行显示“模型服务：服务名称 · 模型名称”，卡片及对话右上角显示“智能体 ID：完整 ID”，使用本地化冒号格式。

智能体消息记录发送时的角色，来源显示“来自主智能体”或“来自子智能体”，并使用与画布一致的 fill 图标；角色后续变化不改写历史来源。未记录角色的消息不猜测身份。AI 工具说明统一使用 main agent / child agent，不使用旧角色称呼 root main。

框选拖动使用独立的 ValueNotifier 和 RepaintBoundary 更新覆盖层；鼠标移动不重建整个工作流、不重新测量所有卡片，也不重复计算布局和连线路由。按下与松开时才更新画布交互状态，松开后统一提交卡片及连线选中结果；4px 拖动阈值、Ctrl／Shift 累加与填充外观保持一致。

拖线预览也采用独立 RepaintBoundary 与可监听的 CustomPainter：指针更新只重绘预览线，不重建卡片、不重绘已有连线和背景网格。开始、结束或取消拖线才更新全局交互状态，继续使用原有 preview 曲线计算；预览层位于卡片下方、选框覆盖层下方，且不拦截鼠标。

正式连线不再读取第三方卡片矩形，也不进行重叠通道检测或分流。无论无关卡片被移动、增删或叠放，既有连线的曲线保持不变；只有两端卡片位置或尺寸变化才更新路径。绘制位于卡片下层，点击与框选共用绘制路径，被卡片盖住的区域优先响应卡片。

框选覆盖层不按原始场景矩形裁切，只由外层画布视口裁切。无限平移后，负坐标区域的选框边框与填充也必须完整绘制；验证需覆盖平移、缩放后的原始场景左侧和上方。

连线端口优先保持分支一致：两张卡片的水平方向存在间隔时，统一使用朝向彼此的左右端口和平滑贝塞尔曲线，不因上下分支高度差较大而切换至顶底端口。只有水平方向没有间隔时才按垂直排列选择顶底端口；不避让其他卡片，不生成直角走线，点击与框选继续使用同一条路径。此规则同时作用于已有连线和新增连线。

智能体卡片宽度保持 252，最小高度从 164 收紧到 144，减少短标题与模型服务之间的空白；文字缩放和长标题仍按内容测量增加高度，端口、选框及连线路由使用实际卡片尺寸。

侧栏“智能体工作流”是返回画布主页的入口：位于智能体对话页时仍可点击，点击后清空页面内对话跳转历史并回到画布；从设备或设置切入时也直接显示画布。只切换显示页面，保留智能体、聊天草稿、运行状态和画布位置，不停止正在执行的工作。

多分支连线不做通道偏移：同一端口发出的不同目标曲线（以及反向汇入的曲线）允许在端口附近自然靠拢，始终保留单条贝塞尔曲线，避免分支增多后出现多余的 S 形弯折。端点完全重合时曲线也允许重合，不因其他连线增删而改变既有路径。自动布局根据分支纵向跨度适当增加水平间距，小型树保持原有间距；手动布置的卡片位置不会为了美化连线被自动移动。

## 模型读取与停止

模型读取结果框的主标题、统计摘要和“选择要添加的新模型”说明固定不滚动，仅新增模型卡片区域滚动，底部操作按钮保持固定。卡片选中与取消选中的边框过渡对齐回收站：167 ms、`Curves.fastOutSlowIn`，不增加点击波纹或按压缩放；系统减少动画时直接切换状态。

编辑服务时，读取模型列表使用独立的二级进度／结果框。取消按钮、点击框外或无选区时按 Esc 均取消本次读取，保留编辑草稿；迟到结果不会覆盖模型列表，也不会关闭其他会话共用的网络连接。成功后显示读取总数、新增数及已有数，直接展示新增模型卡片，默认全选，无复选框或折叠层。选择复用回收站卡片：单击单选，Ctrl/Cmd 单击增减选择，Shift 连选，Ctrl/Cmd+A 全选，Esc 先清空选区；右键菜单可选定或取消选定当前卡片，也可全选当前结果。卡片不显示点击波纹或按压效果。滚动视口延伸到弹窗左右边缘，内容左右留白 24 px，滑块外缘和轨道两端各距承载区边缘 6 px，保留自动显隐且不覆盖卡片或底部按钮。确认后只补入选中的新增模型，原有模型不自动删除，最后仍需在编辑框保存。没有新增时可确认更新服务返回的模型能力信息；空列表与读取失败分别提示，不覆盖已有配置。

手动停止会取消当前回合的网络等待，包括尚未收到响应头的阶段；客户端不等待服务器返回才结束本轮，也不将迟到结果恢复为正文。远端是否立即停止计算取决于服务端对连接取消的支持。停止当前智能体不等于停止整个工作组。

画布停止、对话停止、停止全部及 AI 的 `stop_agent` 共用会话停止核心：取消当前生成、命名请求、权限等待和工具进程，保留排队消息但不自动续跑；停止主智能体同时取消其主持的计时，不连带停止下级。AI 入口先执行管理权限校验。停止全部另行取消所有计时。

手动选择工作区模型／思考等级与 `configure_agent` 共用配置校验和原子更新核心：工作区必须空闲，服务、模型、凭据及思考挡位有效，目标模型兼容已有图片和排队附件；校验失败不部分更新配置。不修改全局服务偏好。手动界面可清空思考覆盖，AI 仍须传入工具列出的明确挡位；AI 的目标管理权限与参数格式检查保留在工具入口。通信连线和上级归属继续作为不同操作，不能因复用底层方法而改变其权限或语义。

## AI 连线与立即引导

主智能体可调用 `connect_agents(from_agent_id, to_agent_id)` 为自己管理组内的两个活跃成员建立双向通信边。重复连接不产生额外边，不改变主从关系，也不启动对话。按任务需要建立直接通信关系，再发送指令、信息或结果；不预设讨论等特定协作流程。跨组连接仍由用户在界面操作。连接沿用现有持久化、工作流导入导出逻辑。

`send_agent_message` 的可选 `mode` 默认是 `queue`；`guide` 与用户点击“引导本轮”共用同一套接续逻辑。主智能体可引导本管理树内任意后代；子智能体只可引导直属下级，即使另有通信连线，也不能引导上级、同级、非直属后代或其他分支。跨工作流不能引导。智能体不能借此恢复被用户停止的智能体或绕过权限确认。常规消息使用排队，只有明确纠正前提或变更任务时使用引导。

### 引导与用时

待发送队列中的智能体来信和聊天消息使用相同的来源样式：正文上方显示主／子智能体图标、名称及完整 ID；用户自己的排队消息不显示来源行。

引导生效时，如果模型正在回复，应用立即停止接收旧输出，保留已显示的正文和用时，再把引导消息带入同一轮的新请求，新段从零开始计时。如果工具调用或权限确认已经开始，引导等这一批操作安全结束后再接续，不取消或重做操作。其他消息仍按原队列处理。若在引导生效前点“停止”，未应用的消息保留在队列，不自动续跑。

投递返回中的 `delivered` 只表示交付，`delivery_status` 区分 `queued` 与 `accepted`，不代表接收方已读或已采用。`reply_completed: false` 提醒调用方不能将同时返回的旧结果当成本条消息的新回复。普通排队回合不自动合并或清空待发送消息。

### 及时汇报

智能体通过 `wait_agents` 等待指定对象时，该对象发来的普通消息可提前结束等待；已排队的匹配消息也可在调用时立即取回。工具在 `reports` 中返回发送者身份和正文，把这些消息交给当前工作轮，不再让同一条消息排队开启下一轮。阶段汇报不代表发送方已完成，仍以 `agents` 中的状态为准。

主、子智能体使用同一规则：上级、下级或同级之间，只要双方已有对应方向的通信权限，且接收方正在等待该发送者，就能及时交回。不新增通信权限，不消费用户消息或其他智能体的排队消息；普通生成、权限确认及未等待该发送方时保持排队。用户手动停止或引导仍然优先，及时汇报不会打断当前模型请求，也不会恢复被手动暂停的智能体。

## 智能体通信动画

参考 Magpie `internal/gui/assets/plugins/routing/routing.css` 的独立流动图层：只有真实发生的 `spawn_agent` 初始分派和 `send_agent_message` 投递触发动画，不能按智能体 busy 状态推测通信，也不在接收方完成普通回复时伪造自动回信。子智能体实际发送回上级的消息沿同一连线反向传输；上级通过 `wait_agents` 或 `list_agents` 实际读取到子智能体的新回复时，也按子智能体到上级方向播放回传动画。同一接收方重复查询同一回复不重复播放，只在子智能体产生新的完整回复后再次触发。普通完成但尚未被读取时，不凭空播放回传。子智能体互发消息同样按真实发送者、接收者确定方向，不能假设连接存储的 from/to 就是本次发送方向。重复消息抑制、参数或目标校验失败不产生动画，无图示端点或没有直接连接也不绘制。

每次投递播放约 1.4 秒：原静态线暂时替换为主题紫色流动虚线，带柔和光晕的紫色圆点从发送端沿现有曲线移到接收端。两向同时投递可同时显示各自圆点，虚线以该线当前首个消息方向流动；结束恢复原有静态线及选中样式。点与线宽按缩放补偿。线条继续位于卡片下方，不拦截输入、不改变路由与连接关系。动画表达消息投递事件，不表示 API 网络进度或接收者工作完成进度。

通信事件通过独立 ValueListenable 发布，仅保留动画期间的发送方、接收方与时间，不存正文、不持久化。到期自动释放事件和定时器；整个工作流销毁时清理所有定时器。独立 RepaintBoundary / CustomPainter 在动画帧重绘虚线与圆点，不逐帧重建卡片、重算路由或重绘网格；静态图层只在通信开始或结束时切换线条。隐藏页面停用 ticker，空闲没有持续帧；减少动画设置下使用静态虚线与圆点提示，不持续运动。

创建智能体的执行模型选择复用聊天输入框 ModelSelector 的完整二级页面与过渡动画：当前模型支持思考强度时打开强度页，可返回模型列表，选择支持强度的新模型继续进入强度页；不支持时直接选择。模型和强度只写入创建窗口的独立会话草稿，取消不修改上级／全局配置；确认后在新智能体首个请求之前应用所选强度。选择继承上级时恢复上级的模型和强度。

画布触发 Ctrl／Cmd+A、C、V、Z、Y，以及 Delete、Escape、空格交互时关闭现有右键菜单；Ctrl+滚轮缩放和滚轮平移也先关闭菜单。键盘删除仅使用 Delete；Backspace 不删除卡片、不解除连线，也不关闭画布菜单。Windows 的 Win 键不作为画布快捷键、提示或多选的 Ctrl 替代键，系统组合键拦截 Win 松开事件时也不会留下画布的 Ctrl 状态。鼠标位于右键菜单上时 Ctrl+滚轮由菜单转交画布缩放并关闭菜单，普通滚轮仍保留菜单本身滚动，不穿透画布。聊天页和文本输入框保持自己的快捷键处理。

## 聊天与记忆持久化

智能体会话、用时步骤、画布位置和长期记忆写入 SQLite，复制卡片同时复制当前有效的独立长期记忆，不保存历史版本。数据包格式、存储页操作与导入冲突规则见[智能体记忆与存储](agent-memory-storage.md)。

右下角缩小与放大按钮之间显示可编辑的画布缩放百分比。输入后回车或失焦沿用平滑缩放动画，以视口中心为锚点；输入框、加减按钮与 Ctrl＋滚轮的有效范围均为 1%–200%，超出自动取边界。Esc 取消草稿，空值或无效输入恢复当前比例；编辑期间不被动画帧覆盖。Ctrl/Cmd+A、C、V 等保留给文本输入框，不触发画布选择或复制。显示订阅变换控制器，仅更新百分比控件，不重建节点或连线。


### 画布底部工具与快捷键预提示

画布铺到页面底边，不再保留横贯页面的底栏与分隔线。缩放、背景、自动布局、重置视图保留为右下角悬浮工具组，距底边 8px；左下角快捷键提示使用同样的底边间距，并避开右侧工具组。提示不接收鼠标事件。

画布拥有键盘焦点时，按住 Ctrl 即提前显示全选、复制、粘贴、撤销、重做及滚轮缩放组合；按住 Shift 显示横向滚动与增选组合；按住空格显示左键拖动平移。组合键按下时提示随当前按键更新，松开或离开画布焦点后收起；不再等操作完成后才短暂显示提示。Windows 下画布不禁用输入法、不改变中英文状态，也不拦截系统候选栏；如果系统漏发 Shift 松开事件，画布通过只读查询实际键位清除残留的 Shift 状态。


智能体卡片右键菜单在“删除智能体”上方提供“删除聊天记录与上下文”，仅作用于右键目标，不扩大到当前多选组。运行中的智能体禁用该操作。执行前显示紧凑的标准确认框，列明目标名称与完整 ID，红色确认按钮、灰色取消按钮；取消不修改数据，确认后再次检查目标仍存在且未运行，再清除聊天记录与上下文摘要并保存，保留长期记忆、智能体本身及其下级关系。

连线的选中与取消选中统一采用 167 毫秒 `fastOutSlowIn` 过渡，点击、Ctrl 多选、框选、全选及取消选择共用同一选中状态。曲线和端点颜色平滑变化，线宽平滑衔接既有选中终态；快速反选从当前显示值继续，减少动态效果时直接应用终态。选中动画只驱动独立连线绘制层，网格背景和智能体卡片不随每帧重建或重绘，完成后停止 ticker；运行中的通信连线仍由原有传输层绘制。

创建主智能体及添加子智能体的窗口提供上下文预算 token 与压缩触发百分比，复用存储设置的数字输入、阈值说明及高百分比预留空间提示。初始值取主智能体模板或所选上级的当前设置（全新默认 272,000 / 90%），可独立覆盖；预算必须是正整数，百分比为 1–100，非法输入不创建节点。参数在注册节点和首次任务请求前应用，后续随该智能体会话保存；取消只丢弃草稿，不修改原模板或上级。

创建主／子智能体和聊天页标题栏共用本机角色卡库，从角色卡列表单独选用。聊天页的角色卡入口位于右上角、智能体类型左侧。空间不足时和模型选择一样隐藏名称和箭头，只保留可点击的头像或图标，悬停提示显示完整角色名；悬停底色与聊天标题一致。空间充足时，箭头在收起时朝右、展开时朝下。已有智能体绑定的卡在读取画布时补入卡库。列表复用权限菜单的双行选项、选中颜色、行间距、圆角及滚动条留白。角色卡显示圆形头像、角色名及已有的作者、版本、格式信息，右侧箭头表示可进入详情。「不使用角色卡」不显示箭头。已选项显示勾选，悬停时使用主题高亮。列表和详情使用与权限菜单相同的淡入淡出过渡，系统减少动画时直接切换。已绑卡时默认打开卡片详情，左上角返回列表。标题和返回按钮固定在顶部，内容区独立滚动。

在「设置 → 智能体 → 角色卡库」可导入卡片并查看绑定数量。卡片右侧的「查看详情」显示标签和作者说明，「删除」会列出受影响的智能体，包括已暂停扮演的智能体。确认后删除卡库副本并解除这些绑定，保留聊天记录和原始 PNG／JSON 文件。受影响的智能体正在运行时，弹窗会提示先停止运行。

「角色卡包」的「导入」按钮可同时选择多个 PNG、JSON 或 `.tar.zst` 文件。单张 PNG／JSON 卡展示卡片信息、角色设定、世界书和高级提示词的只读摘要。批量预览显示新增、重复以及跳过的文件数。批量导入和导出默认全选，点击卡片可切换选中状态，选中项以描边标记。`.tar.zst` 包内为 SillyTavern 角色卡文件。已保存的 PNG／JSON 原件逐字节保留，缺少原件时按酒馆规范生成，有头像则生成 PNG。导入后可在对应智能体里选择绑定。

创建窗口默认不绑卡，选卡、设定或清除绑定只影响草稿。聊天中点列表里的角色卡立即切换并进入详情，保留现有聊天记录。详情提供「启用角色卡」「角色卡设定」和可用时的「开始剧情」。关闭启用开关会暂停角色扮演。选择「不使用角色卡」会直接解除绑定并恢复默认设定，保留消息和卡库副本。若要按新角色重新开场，通过「开始剧情」预览并在有旧聊天时确认清空。

普通聊天只附加简短的回复语言和工具边界说明。启用卡片的「角色设定」后，由卡片提供身份和语气，不再附加默认语言提示；只启用世界书或高级提示词时，仍使用普通聊天的语言提示。工具权限与审批规则不受角色卡影响，计时规则由计时工具说明提供。

卡片角色描述在 64 Ki 个 UTF-16 代码单元内完整保留，导入仍受总元数据大小限制。相同的原始卡片在模板列表中只显示一次，同名但内容不同的卡片仍各自可选。新导入的卡片默认使用角色设定以及卡片中提供的世界书和高级提示词。绑定后可在「角色卡设定」调整这些选项。模板不携带聊天记录，取消创建不会改变原智能体。角色卡带有开场白时，开场列表首项是默认的「手动开场」，选它会清除已选的开场白。也可预览并选择卡片开场白，创建时将其作为第一条角色消息，同时启用剧情。绑定角色卡后工作内容可留空，留空不自动调用模型。填写工作内容则继续按原流程执行。画布卡片用圆形头像显示角色名，点击这行可直接打开角色卡设定，不切换到聊天。画布右键菜单不提供角色卡操作。使用「打开对话」进入聊天后，可在右上角的「角色卡」菜单更换或解绑；导入仍使用设置里的角色卡库。

智能体右键菜单的“复制智能体”只写入复制快照，不立即创建副本；选中多个智能体时显示“复制智能体工作流”。智能体菜单和画布空白菜单均提供粘贴入口，按复制内容显示“粘贴智能体”或“粘贴智能体工作流”，没有可用复制内容时禁用。Ctrl/Cmd+C、V 与菜单共用复制粘贴逻辑，保留所选节点之间的父子关系、补充连接和相对位置；新副本使用新 ID、独立会话且不自动运行，粘贴可撤销、重做。单个智能体的复制不自动包含未选中的下级。

画布粘贴以鼠标位置作为整组节点的左上角，右键菜单使用右键点击时的落点，快捷键使用当前鼠标位置；未取得鼠标位置时使用视口中心。画布导入在打开文件选择器前固定落点，工作流保持内部相对布局，不直接沿用包内的绝对画布位置；放置后选中新节点并保存位置，不移动已有卡片的屏幕位置。平移到负坐标区域时，整体调整场景原点并反向补偿视图，保证新卡片可见且可点击。

导入智能体、聊天记录或工作流包，以及使用长期记忆包新建智能体，都创建新的归属，不弹出逐条记忆检查窗口；仍校验数据并跳过完全重复的记忆。只有向已有智能体合并长期记忆时，才显示记忆检查和冲突选择。

多选智能体时，节点右键菜单仅显示适用于整组选区的操作：复制智能体工作流、导出智能体工作流、连接（恰好两个且尚未连接）、停止（选区中有运行节点）、断开连接（选区有关联连接）和删除所选智能体。打开对话、复制单个 ID、重命名、置于顶层、添加子智能体、身份切换及单个智能体的数据管理均隐藏；粘贴仍可从画布空白右键菜单或快捷键执行，避免在多选菜单中混入与选区无关的操作。恢复单选后正常显示单个智能体操作。
