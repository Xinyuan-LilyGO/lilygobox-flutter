# LilyGoBox 角色卡 / Character Cards

## LilyGoBox 助手

[下载原始角色卡 PNG](./lilygobox-assistant.png)。它是一个冷静、主动的日常助手，可以帮你梳理目标、安排下一步、使用 LilyGoBox 和排查设备问题。需要核对规格或版本时，它会参考 [LilyGO 官网](https://lilygo.cc/)、[官方 Wiki](https://wiki.lilygo.cc/)和[文档源码仓库](https://github.com/Xinyuan-LilyGO/documentation)。

在 LilyGoBox 中打开 **设置 → 角色卡库 → 导入**，选择原始 PNG，然后在目标智能体的聊天输入区选择「LilyGoBox 助手」。没有预设剧情，可以直接开始聊天。角色卡不会自动联网、连接设备或改变工具权限。

头像与 SillyTavern CCv3 角色数据都在同一个 PNG 内。从 GitHub 获取时请下载原始文件，不要截图或重新另存为其他格式，以免丢失卡片数据。
